# A value-only map cannot certify stress, but the actual first jet does

The exact S6.164 map is Fhat=Psi+q8(X)R_old with
X=(partial Psi)^2/kappa. On the entire clock X=1, q8 and its first
seven derivatives vanish. In particular, for arbitrary compact
metric and field variations,

    delta(q8 R_old)=q8'(1) deltaX R_old+q8(1) deltaR_old=0.

This is an identity along the full clock, so derivatives of the zero
first variation also vanish. Hence Fhat=Psi and deltaFhat=deltaPsi.
The variational chain rule for the pulled-back classical action adds
the parent scalar Euler derivative paired with delta_g Fhat. That
term is zero even off shell: no parent background equation, global
inverse, or integrated-out scalar equation is used.

A map with only the same background value would not suffice.
The explicit control q_bad=1-X has q_bad(1)=0 but
delta(q_bad R_old)=-R_old deltaX, which changes the off-shell
metric equation. The actual eightfold clock zero prevents this.

Consequently the actual coordinate pullback cannot remove the
minimal diagnostic's classical null residual. This is a classical
first-variation statement, not a control of all quantum scalar
Jacobian/source terms. Leading nonminimal/derivative action terms
can change the equation and remain outside the minimal diagnostic.
