# Validation contract

This packet has eighteen source/proof/test files and twenty report fields.
Its scientific identities and all prior native reports are reconstructed
read-only, with original SymPy GCD on native, private, ordinary and CLI paths.
The guarded exact-GCD adapter is allowed only in the FULL regression lane.

A cold private preflight and a separately copied fresh preflight must agree
on exact identities, exported APIs, ASCII source bytes and every hash. The
fresh run first populates the complete immediate-parent packets to detect
cache-order dependence. Neither private run may invoke a predecessor's
native writer or rewrite its report.

The accepted raw JSON must be emitted by the persistent native helper and
captured without truncation. Both private and canonical repository copies
are checked against its digest, complete source manifest, all twenty AST
fields, counts, frontier and historical qualifications. The verifier's
literal REPORT assignment determines the canonical path.

Ordinary tests independently compare all fields, reject each field mutation
and unsupported scope, check literal stress-tensor Born contractions, exact
compact bounds, and high-precision original forward cones. CLI and FULL
regression outcomes are recorded in the external assessment, not inserted
later into immutable source. No report or proof is overwritten to hide a
failed preflight; corrections before freezing and their outcomes remain in
the external record.
