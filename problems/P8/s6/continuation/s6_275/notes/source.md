# Unchanged full raw source and explicit reuse boundary

The correction is a canonical transport, not a change of the original
action, source functions or fixed profiles. Reuse the S273 complete
raw Hamiltonian, lapse constraint and original function bindings.
The full relation H_N=C, after only legitimate positive-N primitive
identities, is checked independently here.

All500 complete derivative expressions,63 componentwise RFj bounds
and27 mixed total-order-six entries remain. No sixth real-time
derivative is introduced: the original profiles are only C5 in time,
with the original holomorphic N dependence. Pure-time primitive
contacts remain full N integrals; off-clock functions are not set
to zero. The actual source packet and fixed profile bindings are
included, not just a name or a source hash.

The original wide domain is unchanged: source time1e-130, corrected
evolution time1e-180, source coordinate radius1e-120, lapse radius
1e-115 and homogeneous complex radius1e-122. The source is evaluated
on corrected physical raw invariant images, all explicitly checked
in geometry.py. The correction does not assume those images equal
the old S273 images.

Its exact real-time interval bound, plus1e6 times the full lapse
radius and24e4 times the invariant coordinate radius, is<1e-108.

fluctuating lapse, free-Hessian replacement or scalar-source deletion

The source-only envelopes and homogeneous canonical identities are
unaffected by the missing state dictionary. Their reuse is explicit
and limited: old assertions that an unshifted raw Gaussian is the
same original prepared physical state, or that old/new trajectories
are identical, are not inherited. Full archival native rebuilding
checks immutable contents and historical frontiers, not a repudiated
physical interpretation.
