Freeze only after all private whole-operator, full-payload, source
manifest, scope and independent science checks pass with original SymPy.

and seven proof notes: 17 scientific source files. The certificate has

    ae63ae3c213a5a5cd8b02174ec9eacfd4d19b3d0fb103c05aa221649ead4e05f.

The packet has 45 named identities, 1318 scalar entries, 40 proof gates,
nine controls and 312 rejected inputs. Exact identities cover the whole
spatial generator, density transformation, full off-gauge operator,
principal symbol, finite determinant and nonlinear correction.

retain the boundary flux, use spatially varying full conformal factors,
solve the full nonzero-mode gauge system, test its nonsymmetric
symmetrizer and weak form, and differentiate entire Bessel/exponential
shape families. All three spatial ghost components remain.

After freezing, copy exact bytes to a new checkpoint and run fresh
direct payload/science checks. Native construction rebuilds the complete
ancestry using original SymPy. Transfer raw ASCII JSON with exact
offsets, chunk lengths and observed CONTINUE acknowledgments. Verify the
un-reserialized report SHA, all private/native/repository source hashes,
all 20 fields and every previously protected scientific input.
Never edit frozen sources or reports to repair a launch or test error.

Ordinary package tests and CLI replay use original SymPy. Only the
separately captured full regression uses the audited exact-GCD adapter,
its self-checks and its captured unchanged-input manifest. Use the
existing S219 helper import path when launching that full regression:

    PYTHONPATH=problems/P8/s6/continuation/s6_219/tests \
      .venv/bin/python scripts/p8_replay.py full

Only consumed successful exit statuses count as completed validations.
External publication notes record actual counts, timings, hashes and
any development retries; frozen proof notes do not predict passes.
Publish only after required native, direct, ordinary, CLI and captured
full checks pass, using the exact explicit manifest and independently
checked remote hash. Preserve unrelated P4/P9 work.

The algebra and finite diagnostics support written local
implicit-function, weak-coercivity, elliptic-regularity and finite
determinant arguments. They do not formalize those arguments or turn
the diagnostic into a continuum quantum measure.
