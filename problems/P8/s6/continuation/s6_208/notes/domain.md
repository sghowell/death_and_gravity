# Explicit joint inverse-radius and time domain

Let Amax = 25/16, epsilon = 1/100, rho = epsilon/(m+|P|), and use the original outer time radius rO = 1/10000. For |x| <= rho,

|xP| <= epsilon, |mx| <= epsilon.

The scaled second-leg square differs from one by at most eg = 2epsilon+epsilon^2. The relative time-scale defect is ea = 6rO/(1-6rO). Relative to the real-center baseline 1/a0^2, the complete squared-frequency defect is at most

ew = ea+(1+ea)eg+Amax^2 epsilon^2
   = approximately 0.02095657 < 1/40.

The positive analytic square-root branch therefore has Re Omega > 0.98/a0 >= 0.98/Amax and |Omega| < 2. Also

|z| <= 1+Amax^2 epsilon^2/(1-ew) < 1.01.

The actual W8 coefficient majorants from S6.186 remain valid on this domain: |u| < 0.51, |1+u^2| > 0.7 and |z| < 1.01. The full relative What correction is bounded by the sum of all four B_q [Amax epsilon/(0.98m)]^(2q), which is smaller than the already established old ratio bound and below 0.001.

Hence Re What > 0.98/Amax-0.002 > 1/2, |What| < 3, and each normalized inverse summed phase has modulus below one.

This is an explicit new domain in complex inverse radius. It is not obtained by assuming that an earlier estimate with real internal momentum automatically extends to complex internal momentum. The physical mass, full comparison frequency and actual prepared state are unchanged.
