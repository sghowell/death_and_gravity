The scientific manifest has18 files: seven package modules, two
test modules, README and FORMULATION, and seven proof notes.
The immutable report has20 top-level fields,44 named exact
checks and6613 checked scalar entries. Most scalar entries arise
from complete matrix identities and the6144 connection derivative
checks; they are not6613 independent scientific theorems.

inputs, preserving nine primitive and119 matching frontier rows.

Exact symbolic checks include the original initial lapse equation,
its full positive root, all bare comparison Euler identities,
correct physical Hubble and proper acceleration, the weighted
reference Legendre boundary, symplectic and original endpoint
inverses, source Bell/Cauchy factors, the complete heavy energy
identity, and the finite-band arithmetic.

Independent science tests also reconstruct the whole Hamiltonian
by quadratic polarization, compare generator derivatives with
finite differences, sample exact interval enclosures, test positive
energies with NONCOMMUTING scalar matrices and the actual heavy
mass, and integrate full16-phase moving-energy fixtures.
Bare nonlinear ODE fixtures test constraint preservation and the
physical-turn formula at finite numerical displacements. Those
fixtures are diagnostics, not full-parent numerical solutions or
proof of the quantified actual tiny family.

A required negative control retains nonzero R_uu when R_u=0 at
the initial time. Erasing it leaves a nonzero original constraint
residual. This guards the derivative-atom substitution mistake
caught and corrected during private development.

Native, direct, ordinary and CLI validation use the original
SymPy polynomial GCD. Only the captured full P8 regression may
use the separately audited exact-GCD adapter. Runtime warnings
are errors in independent science tests. Ruff checks, a complete
private preflight, a fresh repository preflight and a source-pinned
native rebuild precede publication. Independent ordinary, CLI
and full replays must each reach observed zero exit; collection,
partial output, a completed different manifest or process survival
is not completion evidence.

Every source and report hash is compared before publication.
Frozen predecessor bytes and private frozen originals are never
edited. External assessments record actual timings, manifests,
development failures and subsequent successful checks. No
quantum, cutoff, nonlinear-inhomogeneous or original P8 closure
is inferred from passing arithmetic or replay tests alone.
