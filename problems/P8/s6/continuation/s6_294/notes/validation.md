# Reproducible validation contract

The immutable source inventory is seven Python modules, two test
modules and nine Markdown files. The verifier's20 fields are derived
from its actual return AST and mirrored in the test contract. It
rebuilds S6.293 and all accepted ancestry and checks the frozen parent
raw report hash. Every scientific residual/payload is exact; numerical
calibrations live only in the tests.

Before freezing, run the entire private preflight with original SymPy,
then a fresh copied package with all immediate-parent packets forced
before its own residuals. Compare source bytes and hashes. Only after
both pass may identical sources be copied into the repository.
Native replay must preserve its protected inventory and emit the raw
report through the exact chunk/ACK protocol. Both private/repo copies
must agree byte-for-byte, with matching source hashes, AST/counts,
frontiers and historical qualifications.

Final publication separately requires original-SymPy ordinary and
CLI replay and a complete captured FULL snapshot containing this
packet. The exact-GCD adapter is guarded and FULL-only. An earlier
FULL snapshot does not validate later source files. Frozen sources
and raw reports are never rewritten to fit a later assessment.

Independent research tests check full general-D/D4/D5/D6 tensors,
all twelve labelled box assignments, full light/HH cuts, the entire
physical weighted logarithm, complete dimensional raw-graph versus
finite-limit comparisons at three subthreshold mass/scale/kinematic
points, and the explicit analytic majorant constants.

The independent literal-box integral caught a provisional plus sign
in the finite integration-by-parts K term. It was corrected while
unfrozen; the correct term is negative. Its rejected sign has a
nonzero exact defect and the implemented sign is separately tested.
The corrected48/96-node numerical comparisons converge toward the
whole finite expression. Their finite quadrature agreement is a
calibration, not a rigorous estimate at10^-1001. That bound follows
from the written positive-domain majorants and exact original numbers.

An early private module assembly had indentation and test-decorator
syntax errors, corrected before preflight. Outcome counts, timings,
native hashes and final regression evidence belong in the external
publication assessment, not in edited frozen scientific sources.
