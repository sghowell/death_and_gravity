# S6.332: remaining-energy logarithm and common-space soft cutoff

Original V/G/B/P8 remain OPEN; scoped P8(a) is unchanged.

The fixed-Born D4 leading cloud is coupled to its retained-energy cutoff
on one probability space. For the same limiting additional-soft insertion
Z=deltaDelta+deltaa*ln(x-R), retain each state's remaining energy and its
exact total-energy conditioning. The signed-density L1 difference is
bounded by 63000*a*eta*(1+ln(1/eta))^2/kappa, hence by the strict original
bound 51000*eta*(1+ln(1/eta))^2/kappa^2.

This is not TV convergence of finite/infinite emission-configuration
laws. Those laws are singular for a>0. It is also not a joint regulator
estimate, outer hard matching, interacting probability or P8 closure.
