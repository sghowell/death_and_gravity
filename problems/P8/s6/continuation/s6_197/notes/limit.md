u_actual=alpha_initial u_W8+e. The true initial Bogoliubov
coefficients obey |alpha_initial|^2-|beta_initial|^2=1.

residual in the exact curved-background mode equation.

as a new physical CCR state, a conserved reference source,
or a metric derivative of the fixed effective action.

substitution into the finite mode formula, not by such a
claim. Independent Wronskian tests make the distinction
explicit even for a simple exact-frequency fixture.

supports. What remains singular is the REFERENCE memory

diagonal. A finite remainder does not set those local terms.

assumed. The actual original prescription is unchanged.

comparison is not a small full determinant response.
