# A sharper complete transition bound and a local energy difference

The [formulation](FORMULATION.md) fixes the observable and
domain. The [complex-disk proof](notes/complex_disk.md)
controls four [exact frame rotations](notes/frames.md).
The [energy proof](notes/energy.md) distinguishes the
out-particle energy from the local in/out state difference.

The [native report](certificates/polynomial-vacuum-superadiabatic-state-energy.json)
pins fourteen source/proof/test files. Replay this directory
as the ordinary target, or use
p8_vacuum_superadiabatic_state_energy.verify for CLI replay.

No final off-diagonal term is set to zero. These bounds
retain the complete quadratic evolution but do not control
absolute stress, interactions, a curved state or original
P8 closure.
