# Validation and frozen evidence boundaries

The publication manifest has17 scientific sources: six modules, two test
files and nine Markdown formulation/proof files. The native report has20
top-level fields and pins the full S253 parent report by raw SHA256.
Native replay rebuilds the full unchanged ancestry, while the preflight
checks the pinned parent bytes and its scientific source manifest.

Exact checks cover the full heavy density, source-pinned coefficient
mapping, complete four-velocity/three-auxiliary reduction, eight-phase
physical and time-dependent canonical charts, whole fast matrix and
rational remainder, all16-phase characteristic, an independent full
rank-one determinant, and the exact growth normal form with slow
nilpotent block. The written compactness, invariant-cone and Fourier-
packet arguments are not FORMALIZED by finite symbolic tests.

Independent diagnostics re-enter polynomial source densities, numerical
full Legendre equations, exact chart derivatives, finite-momentum full
spectra and time evolution. Diagnostic parameter sets are not the giant
physical mass or an evaluated Wilsonian threshold. Domain/scope controls
reject missing positive pivots, r0 or L2zero in the nonreference proof,
nonexact data and every unsupported promotion of earlier obligations.

Private exact/science checks precede freezing. Native/source/field hashes
and a fresh repository preflight must agree before publication. The raw
native report is transferred without JSON parse/reserialization and its
ASCII/LF bytes, chunk framing and SHA256 are checked. Ordinary and CLI
replays are read-only and use original SymPy, as do native/direct science.
Only the complete captured P8 regression uses the audited exact-GCD
adapter. Only one full regression runs at a time.

Actual source counts, native transfer details, replay results, captured
test-file hashes, publication and independently checked remote hashes
belong in the external dated assessment. They are not inserted by editing
frozen scientific files. Publication uses an explicit21-file manifest and
preserves unrelated P4/P9 changes. No earlier source, proof, test or native
report is overwritten. Original P8 is not marked complete by this audit.
