# Validation protocol and evidence boundaries

All18 source files are ASCII, newline terminated and separately hashed.
Native/direct/ordinary/CLI use original SymPy. The narrowly scoped exact
GCD adapter remains FULL-only; no private preflight changes that rule.
The canonical native report has exactly20 fields and compares the entire
recomputed report, including every source hash, to the captured bytes.
The current packet has268 exact named/scalar checks,50 proof gates,
8 controls and73 rejected inputs. No numerical float enters its
scientific symbolic payload.

Independent science checks include the literal projective Jacobian,
the original u,h box integrals, complete Box16 finite normalization at
subthreshold and physical points, nonzero wrong-sheet and omitted-J1
controls, three radial endpoint moments on complex points, exact all-angle
Born positivity near both endpoints, the quartic premise, and rejection
of unsupported domain or matching-closure assertions. Written uniform
proofs carry the inequalities; numerical samples are supplementary.

The initial private unpartitioned20-digit box quadrature missed a1e-17
tolerance by8.47e-17. Resolving its explicit h~u^2 A/n corner and using
35digits fixed that diagnostic. The first direct module probe also
exposed a noncanonical exact0*I after factorization; expanding the literal
complex polynomial before factoring gives canonical zero. Neither issue
was hidden by changing a frozen file or by an adapter.

The first full cold preflight then passed all exact/serialization checks
and449 science tests. Its two35-digit original-box integrations missed

general exact identity and uniform bound are unchanged.

Cold and distinct fresh-root preflights must validate all exports, exact
checks, gates, scientific serialization and tests. The fresh root forces
the complete immediate-parent packets first. Only after both and the
three-way source comparison pass are sources frozen. The native helper
then receives one specification, with only its documented continuation
ACKs; raw bytes, hash, canonical REPORT AST, source hashes,20 fields and
frontier cardinalities are validated before freezing the report.

Own ordinary/CLI and the separately captured FULL selection are further
acceptance requirements, recorded in an external assessment. A native
report is not evidence that those later runs have passed. No source
is retroactively edited to insert later outcomes. At most one FULL and
one ordinary/CLI pair run; no process/resource diagnostics or blind
restart is part of this protocol.
