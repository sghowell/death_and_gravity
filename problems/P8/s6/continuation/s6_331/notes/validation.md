# Independent exact reconstruction and immutable evidence

Private cold and independently started fresh reconstruction use original
SymPy. The fresh process first rebuilds the actual frozen immediate
parent's complete own science packets; any subsequent ancestor-cache
reuse is explicitly disclosed. No successor import precedes its one
START gate after final source-copy equality.

The preflight checks all four actual direct report hashes and entire
source manifests, source-set/20-field AST/export equality, all exact
residuals and proof gates, exact payloads, counts, tests and unchanged
final source bytes. Only equal cold/fresh hashes authorize a byte-exact
repository copy and one native submission.

Whole native bytes, SHA256, AST, source manifest and inherited frontiers
must validate before storage. Frozen science and raw evidence cannot
be rewritten to hide a failure. External ordinary tests, a separate
read-only CLI and a complete FULL source replay must also finish at C0
before publication. Original SymPy is unchanged outside FULL; only
FULL may use the separately audited exact-GCD adapter and must restore
the original backend. Partial runs are not acceptance receipts.
