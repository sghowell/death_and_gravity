# Reconstruction and acceptance boundary

The packet reconstructs all16 sector/basis currents directly from
the unchanged action. It does not accept a private precomputed current
or a grid of finite points as a uniform proof.

Independent routes include:
- literal MetricJet EH3/EH4 and32 complete pair/root comparisons;
- a generic16-entry inverse/projection identity;
- exact retained-factor, division, representation and energy-factor checks;
- independent nilpotent Taylor coefficients, including96 baseline and
  768 reconstructed-case component coefficients;
- positive-coefficient derivative certificates and288 joint-axis rows;
- symbolic angular reflection plus16 independent covariance oracles;
- all24 independent spatial orientations of the original47 hard root,
  and four188-class contractions at real/Gaussian-rational recoil points;
- independent EGF coefficient convolution, product-rule arithmetic
  and exact integrable-kernel identities.

The private exploration preserved time-budget incomplete attempts,
unsupported support searches, and genuine counterexamples to a
stronger1/W derivative shortcut. Those are not passed uniform proofs.
A mistaken zero-vector shape and an import of an older source API
were diagnosed before the corrected independent runs; no assertion
was weakened. The accepted formula retains the pair-energy scale S.

The first consolidated-current comparison reached its internal mathematical
checks but the external harness then requested a newer metadata field from
the oldest cache schema. That KeyError was a harness failure, not accepted
comparison evidence. The package tests reconstruct and compare the exact
recorded basis budgets explicitly, without depending on that private schema.

Cold and separate fresh-root scientific reconstruction precede source
freeze. All18 ASCII source files must agree byte-for-byte between
private, fresh and repository roots. One native specification then
rebuilds the20-field report. Complete chunks alone are acknowledged;
there is no probe, resend or premature native acceptance.

External acceptance additionally requires original-SymPy ordinary
tests, independent CLI replay, the captured complete P8 regression,
unchanged source/raw hashes, exact staged paths and staged-byte equality.
Only FULL may use the exact-GCD adapter. Actual counts, report hash,
run outcomes and publication receipts belong in the external assessment.
This procedural note does not predeclare an unfinished run successful.
