# Independent checks and their limits

The matrix rotation, moving-basis connection
and norm conservation are checked directly.
The twice-integrated expression is derived
by literal symbolic differentiation before
substituting the mass/frequency inequalities.

Independent quadratures check the profile's
absolute derivative integrals, tail bounds
and both radial beta-function integrals.
Zero momentum and constant mass give no
transitions. The opposite active profile
has the same allowance.

Finite-interval mode tests solve the complex
interaction equations while accumulating
the first transition integral separately.
Step refinement and mode-norm checks are
retained. Test parameters resolve a nonzero
higher-transition correction; it is compared
with the explicit odd-series bound.

The finite test interval is not silently
called the whole real line. The monotone
profile tail bounds the omitted mixing norm.
An independent constant-phase two-level
control has beta=sin(eta) and I1=eta, detecting
the error from discarding all higher terms.

These numerical ODE tests are diagnostics,
not validated integration or proof of the
actual extreme-parameter evolution. The
actual bound instead follows from the
written uniform inequalities and exact
rational calibration. Source-pinned replay
is not formalization or independent peer
review.
