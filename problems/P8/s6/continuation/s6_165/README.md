# A specified quadratic in/out state with an explicit transition remainder

The [formulation](FORMULATION.md) fixes the free flat
Dirac problem and its observable. The
[transition proof](notes/transition.md) retains all
higher transition terms, while the
[energy proof](notes/energy.md) fixes normalization
and the distinction from local stress or backreaction.

The [read-only native report](certificates/polynomial-vacuum-flat-dirac-production.json)
pins the sources, written proof and independent tests.
Replay with this directory as the ordinary target or
p8_vacuum_flat_dirac_production.verify as the CLI module.

This is a quadratic-state building block, not the
complete interacting or curved common-parent state.
Original P8 remains OPEN.
