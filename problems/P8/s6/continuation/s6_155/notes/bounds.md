# Parameter-integral and actual numerical enclosures

At the fixed scale mu=m=10^200, the scalar kernel has
1<=D<=M<=mu^2 and integral b<=1/(2M). Thus
|r1|<=1200g/(2QM), with Q>144 and ell<1200.

For the fermion, 0<=l_x<=bmax=1/(4m^2-1).
Consequently J1<=bmax/6 and J2<=bmax^2/6. With pi<4,

    |fp1|/(4NY/Q)
      <=bmax/3+bmax^2/4+2/3 <1     for m>=36.

The inherited real-slope proof also gives
0<fp0<4NY/(3Q). Using the same rational upper bound for Y
as S6.131, set

    k0_up=g/(2QM)+4NY/(3Q),
    k1_up=1200g/(2QM)+4NY/Q.

At the actual parameters these are approximately
3.84413165810667e-207 and 3.28629105179398e-205.
The first-field second-order amplitude bound is
3.43692152926923e-213 relative to tree, below 10^-212.
The tree-square piece alone is below 4.43320446145740e-413.
The local coefficient-map commutator is separately bounded
by 5.22341895388601e-412 relative to tree.

Exact rational comparisons enforce the bounds; these
rounded displays are not substituted into the proof.
The positivity of 1-k0_up refers only to the first-factor
algebraic representation. It is not a new full two-loop
normalization theorem or a physical higher-order remainder.
