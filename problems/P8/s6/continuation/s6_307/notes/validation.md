# Validation protocol and evidence boundaries

All18 source files are ASCII and newline terminated. The canonical
native report has exactly20 fields, including every source hash.
Native/direct/ordinary/CLI use original SymPy; the exact-GCD adapter
remains FULL-only. Symbolic science payloads contain no Python or
SymPy floats.

The packet contains293 exact named checks,326 scalar entries,
56 proof gates,8 controls and73 rejected inputs.
The complete source/frontier chain is preserved. Exact checks include
the full tensor shift, trace-reversal reciprocity, physical TT emission
identity, all18 external groupings and all rational bound constants.

Independent tests compare the original scalar-propagator diagrams,
test all18 required nonzero off-shell shifts, evaluate physical
paired-current inequalities, and check12 simultaneous forward/soft
configurations on both sides of the energy split against the complete
original21-gravity-diagram amplitude. Log-energy quadrature calibrates
the high-band integral and entropy bound. Exact domain tests reach
arbitrarily small transfers; log-domain detector tests retain
alpha*lnx whenx=exp(-kappa*chi). These samples supplement, not replace,
the written all-angle proof.

Cold and distinct fresh-root preflights must pass all exports, exact
checks, proof gates, float-free serialization and scientific tests.
The fresh-root run first forces the entire immediate parent's packets.
After both and the exact three-way source comparison pass, sources
are frozen. Only then does the existing native helper receive one
18-source/20-field specification; its only subsequent inputs are the
documented continuation ACKs. Captured raw bytes, digest, canonical
REPORT AST, manifests and frontiers are validated before freezing
the report.

Own ordinary/CLI and a separately captured full P8 suite are later
acceptance gates. Their outcomes belong in an external assessment,
not these frozen sources. At most one FULL and one own/CLI pair run.
There are no process/resource diagnostics or blind retries.
