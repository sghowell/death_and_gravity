# Independent reconstruction, controls and immutable evidence

Private probes checked the exact phase/beta relation, regulated
decomposition, weighted radial integrals, beta derivatives, both
endpoint logarithms and all stated budgets. Independent quadratures
include rare index and extreme resolution. The saturating radial
majorant models are explicitly NOT original physical-current
calibrations; they support the arithmetic, not the physical proof.

The initial uniform-cutoff probe had a syntax typo and then an
unexpanded digamma/trigamma recurrence residual. Both were corrected
in the private probe before acceptance by applying exact recurrence
normalization to the whole difference. The separate joint-rate probe
then passed all 16 exact checks, 10 gates, 4 radial integrals,
24 conditional log-square integrals and 9 majorant models with seven
frozen physical inputs unchanged. No frozen parent was edited.

Cold and independently started fresh reconstructions use original
SymPy. The fresh process first rebuilds the complete frozen immediate
parent packets, then waits for one START after byte-exact final source
copying. Completed ancestor-cache reuse is disclosed. Preflight checks
actual parent raw/source hashes, source-set/20-field AST/export equality,
exact residuals, proof gates, API guards and unchanged source bytes.

Only matched cold/fresh hashes authorize the repository copy and one
native specification. Complete native raw bytes, manifests and inherited
frontiers must validate. Ordinary tests, a separate read-only CLI and a
covering FULL source regression must also finish C0 before publication.
Only FULL may use the audited exact-GCD adapter and it must restore the
original backend. Frozen evidence is not rewritten to hide failures.
The result is written analysis plus exact algebra, not kernel formalization.
