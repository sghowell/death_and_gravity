# One reference space, two regulators and the exact mark

Use the original action, fixed physical hard E,u and fixed Born D4
leading intensity Lambda(dn) dw/w, with index 0<=a<=1. The original
a<4/(5*kappa), kappa=10^800, is not expanded.
Let sigma be the full angular-energy cloud and sigma_eta its retained
w>=eta part. Let A={R<=x}, A_eta={R_eta<=x}, p=P(A), p_eta=P(A_eta),
with 0<eta<=x<=1/8. Each mark is evaluated only on its own physical cut.

For 0<epsilon<=1/8 keep exactly the original additional-soft insertion
Z_e(sigma;y)=[deltaa_e(sigma)*y^(2e)-deltaa(sigma)]/(2e),
with the same Born subtraction at the SAME remaining energy y.
At e=0 define Z_0=deltaDelta+deltaa*ln y.
On the same full Poisson space set
f_e=1_A*Z_e(sigma;x-R)/p and
f_e,eta=1_A_eta*Z_e(sigma_eta;x-R_eta)/p_eta.
Outside an applicable event set its density to zero without evaluating
the physical mark. Positive endpoint equalities are null; the zero-index
and zero-radiation marks vanish exactly.

Put L_t=1+ln(1/t). The joint total variation NORM, without a factor 1/2,
obeys E|f_e,eta-f_0|
 <=[132000*a*eta*L_eta^2+400000*e*a*x*L_x^2]/kappa.
At the original parameters it is strictly below
[106000*eta*L_eta^2+320000*e*x*L_x^2]/kappa^2.
For separate error estimates use non-strict bounds at e=0 or R=0,
where both sides of the relevant regulator estimate vanish.

At fixed x and hard data this gives arbitrary joint and both iterated
limits. Only the additional soft factor has been dimensionally continued;
the outer state/reference remains physical D4 and fixed Born.
