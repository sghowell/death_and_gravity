# S6.333: quantitative joint additional-soft regulator limit

Original V/G/B/P8 remain OPEN; scoped P8(a) is unchanged.

For the same fixed-Born D4 leading reference and specified additional-soft
insertion, both the infrared cutoff eta and dimensional regulator epsilon
have an explicit common-space signed-density L1 error bound. The original
physical bound is
[106000*eta*L_eta^2+320000*epsilon*x*L_x^2]/kappa^2,
where L_t=1+ln(1/t), 0<eta<=x<=1/8 and 0<=epsilon<=1/8.

The proof retains the original projector, radial and phase convention,
actual remaining energy and both conditioning-normalization errors. It
gives arbitrary joint and both iterated limits at fixed resolution and
hard data. It is not outer hard matching, an interacting probability,
configuration-law TV convergence or original P8 closure.
