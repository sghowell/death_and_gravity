# Immutable-source validation and evidence boundary

The manifest has eighteen ASCII files: seven Python modules, two
test files and nine Markdown files. The native report has twenty
fields. Whole-source hashes,343 named residuals/448 scalar entries,
132 proof gates, eight
controls,73 rejected inputs, nine primitive records,169 matching

The scientific tests distinguish general symbolic identities,
exhaustive topology, written analytic inequalities, exact original
amplitudes and supplementary quadrature. They do not infer a uniform
continuous-domain theorem from sampled energies or angles.
Scientific payloads reject both Python and SymPy floats.

Before freezing, format/lint only the unfrozen private packet, run
its cold entire-source/science preflight, copy all eighteen files
to a fresh private directory and force the whole S312 parent packet
before the new preflight. Then compare private, fresh and repository
bytes and hashes. The native helper receives one specification and
protects all earlier frozen inputs. Only complete output chunks are
acknowledged. The exact raw report is checked in both copies against
its source manifest, counts, frontiers and twenty-field builder AST.

Original SymPy is retained for native/direct/ordinary/CLI validation.
The audited exact-GCD adapter is FULL-only. Ordinary native equality,
independent CLI replay and captured full-suite acceptance are separate
gates; commands, actual counts, times and exits belong in the external
assessment after completion. No frozen ancestor is edited to fit a
new result, and no pending external validation is claimed as passed.

During private implementation, ordinary Python integer division in
two budget records introduced floats; both were changed to explicit
exact Rational construction before any source freeze. The strict
recursive payload check then passed. An initial scratch count probe
omitted the repository scripts import path and stopped at import;
adding that path reran the same scientific inputs. No numerical
tolerance, physical parameter or original SymPy backend was changed.
