# Reproducible checks and their proof boundary

The source modules contain exact full-source and canonical identities,
complete finite group actions, all retained derivatives, and outward
rational analytic budgets. Written analytic and operator proofs are
separate from symbolic residual checks; this is not formal verification
of Banach's theorem, Cauchy's theorem or the Schur argument.

The science tests exercise every500 whole-source derivative envelope,
all196 phase growth ratios, all63 componentwise source jets, all24
cubic actions, independent reconstructed-wave covariance checks,
canonical-density force transformations, averaged implicit remainders,
the weighted maximum contraction metric, scalar-phase restoration,
operator/expectation bounds and unsupported-input rejection. Tests
distinguish actual source contacts from fixture specializations, and
quantitative estimates from numerical diagnostics.

The certificate contract independently compares every field of the
entire read-only report, its exact source hash map and the unchanged
immediate predecessor report. Missing, extra and mutated fields fail.
The native/direct/ordinary/CLI rebuilds use original SymPy; an audited
exact-GCD adapter is permitted only in a separately captured complete
regression replay. A local fixture or source-only preflight is never
reported as a full ancestral rebuild.

This file specifies the validation contract, not a claim that a pending
run has completed. Observed commands, exit codes, counts, hashes and any
failed unfrozen prototypes are recorded in the external assessment.
Source files and the final native report are immutable after exact-copy
acceptance. Later corrections must be new packets or external errata.
Historical successful replay does not reverse the S261 physical
refutation or S265 unlocalized integrability obstruction.
