# Validation boundary

Exact checks compare the literal prior cut density, rational
endpoint and tail completions, product and chain derivatives,
outward-rounded constants, C2 partition identities, one-band
Fourier normalization, all-band sums, massive scaling and the
current inverse's parameter substitution.

Independent tests evaluate the full density and first two
derivatives at high precision across threshold, overlap and
many tail decades; compare the integral representation of the
analytic threshold function; check compact partition derivatives,
finite telescoping, continuous inequality fixtures, spectral
Laplace transforms and sine normalization. These fixtures are
supplements, not the continuum proof or an optimal norm estimate.

The threshold, tail, Fourier summation and identification
arguments are written in full. Their analytic steps are not
advertised as FORMALIZED. In particular no floating-point
quadrature of an oscillatory infinite-frequency integral
defines the claimed L1 bound.

The report has an explicit18-file scientific manifest and
20 fields. Read-only equality, exact source hashes, per-field
mutation rejection, unsupported scope rejection and frozen
prior report/source reconstruction are separate controls.
Scientific code, tests and proofs are frozen before native
report capture; report bytes are transferred losslessly.

Native, direct science, ordinary and CLI use original SymPy.
Only the complete captured P8 regression uses its audited
exact GCD adapter. New checkpoint/source capture never
rewrites a frozen predecessor.
