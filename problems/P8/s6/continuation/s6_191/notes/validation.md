# Verification boundary

The continuous mixed-jet, finite-reference, exact
error, covariance and infinite-tail arguments are
in mixed.md through tail.md. Tests supplement those
proofs; sampled modes are not the uniform argument.

All prior zero-parameter finite constants are compared
exactly. Independent mixed matrix-exponential and
positive-root fixtures check the noncommuting
derivative recurrences. Ordered reference parameter
jets are compared with independently differentiated
finite references. Full first/second error equations,
inverse and six-quadrature covariance derivatives
retain every product-order and adjoint contribution.
Independent infinite-tail and Taylor checks retain
the varying frequency weight.

Private algebra expands Gaussian-rational matrix
products between operations to avoid repeated factoring
of large unevaluated expressions. This changes neither
SymPy nor the mathematical expression. Frozen scientific
bytes may not be changed.

The manifest has seven source files, seven proof notes,
two root documents and two test files. The report has
twenty explicit fields and scope mutations are rejected.
Native, direct science, ordinary and CLI use unmodified
SymPy. Only the complete captured regression uses the
audited exact GCD adapter with immutable snapshots and
original tuple self-tests. Final exit code0 is required.
