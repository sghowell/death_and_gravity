independent fresh-copy interpreter, forcing the whole immediate parent's
packets before own residuals in the second. Require equal18-file ASCII
manifests, exact symbolic payloads without floating-point entries, all
written-proof gates, rejection controls and the full scientific test file.

The algebraic evidence includes an independent determinant/adjugate
seagull derivation, general invariant-index Ward polynomial, exact rational
component shells/conservation/gauge checks, full-channel invariant versus
component comparisons, Bose symmetry and canonical Born calibration.
A wrong cubic sign is rejected. Exact rational soft families calibrate
both TT polarizations. Finite points supplement the written general
identity and the explicit component/propagator/phase-space inequalities.

After freezing, create the native20-field report once with original
SymPy, retaining exact ASCII transport and all source hashes. Validate
private and repository raw copies, canonical REPORT path, field AST,
counts and unchanged original frontiers. Do not edit frozen artifacts.

Acceptance separately requires own ordinary pytest, native CLI --check,
and a complete captured P8 FULL regression. Only FULL uses the audited
exact-GCD adapter; native/direct/ordinary/CLI retain original SymPy.
Record actual sessions, timings, counts, failures and publication hashes
in an external assessment. This note does not predeclare those outcomes.
