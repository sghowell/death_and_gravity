# Cold, independent fresh and immutable native evidence

Original SymPy is required for private cold/fresh reconstruction and
all ordinary/CLI checks. The preflight pins all four actual frozen
direct reports and their complete source manifests, checks residuals,
proof gates, counts, exact payloads, physical parameters, tests and
source hashes. The independent fresh process reconstructs the frozen
immediate parent's whole own science packet before importing this
successor; completed-parent cache reuse is explicitly disclosed.

Only equal final cold/fresh source hashes authorize a byte-identical
repository copy and one native-helper submission. The complete native
raw bytes, SHA256,20-field AST, manifest, direct provenance and all
frontiers must validate before storage. Frozen science and raw output
are thereafter immutable.

Native completion is not publication acceptance. Ordinary tests,
a separate read-only CLI and complete FULL source replay must also
finish at C0 against captured bytes. Only FULL may use the scoped
exact-GCD adapter and must restore the original backend. Draft and
harness failures, if any, remain external; no partial run is a pass.
