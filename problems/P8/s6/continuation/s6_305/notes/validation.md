# Validation and independent checks

Before source freeze, run a cold private interpreter and an independent
fresh-copy interpreter. The fresh run forces the whole immediate parent's
packets before evaluating its own. Require the same18-file ASCII manifest,
exact symbolic payloads without floating-point entries, all residuals and
written-proof gates, rejection controls and the entire scientific test file.

Independent checks include massive component stress contractions in all
three channels, full nonforward scalar and nine-polarization Proca cuts,
both inverse-kernel signs, direct spectral versus radial quadrature,
closed radial functions at real and complex arguments, and lower-bank
Feynman boundary values. The wrong principal-square-root product is a
negative control. Zero-momentum subtraction, original finite source
coefficients, same-axis matching derivatives, exact all-nonforward-domain
checks and explicit positive arithmetic margins are retained.

These numerical finite-point comparisons supplement exact identities and
the written uniform denominator, weight, Born and logarithm inequalities.
They do not establish uncomputed all-order physics.

After freezing, generate the native20-field report once with original
SymPy, capture the exact ASCII transport, and validate both private/repo
raw copies with canonical REPORT AST, source hashes, counts and unchanged
frontiers. Do not mutate frozen scientific sources or raw records.

Own ordinary pytest, independent native CLI --check and captured complete
P8 FULL regression are separate acceptance requirements. Only FULL may
use the audited exact-GCD adapter. Actual sessions, timings, counts and
any prefreeze failures belong in an external assessment, not a retroactive
edit to these frozen scientific notes.
