# Verification boundary

Written proofs cover the variable complex disks, arbitrary-order
exact-frame recursion, both physical time tails, complete momentum
integrals and all-order Hadamard comparison. The external theorem
is used with an explicit geometric and Clifford dictionary, not
formalized by this repository.

Independent tests use the full SAT8 and scale-factor functions,
exact Pauli rotations, finite Taylor jets evaluating derivatives
of the exact functions, complex disks, radial quadratures,
all-order high-momentum thresholds and projector Sylvester
identities. Such finite tests supplement the analytic proofs;
they are not validated integration or a formal proof.

The new source, notes and tests are developed privately. After final
science and serializer preflight they are frozen byte-identically.
The native report is transferred losslessly, hashes checked, and
fresh ordinary, independent CLI and full captured-snapshot replays
are required before publication. Native, direct science, ordinary
and CLI use original SymPy with interpreter-only allowances.
Only full regression uses the separately audited exact GCD adapter.

No old source, proof, report or regression file is changed.
A failed private diagnostic must be resolved before freeze and
recorded in the separate publication audit.
