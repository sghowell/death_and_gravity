# Both-leg projection and weak commutator limit

The actual state is pure Gaussian. Wick-centering a quadratic
smeared stress removes its vacuum scalar, while its number
and annihilation terms kill Omega. Thus psi_f lies exactly in
the symmetric two-particle Hilbert space. The creation kernel
is symmetric, and its norm has the S186 pair-exchange factor2.

Project the field to the common spherical band |k|<=K before
forming the centered observable. Its vacuum vector is precisely
P_K^(2)psi_f, where P_K^(2) projects BOTH created momenta.
This is the SAME orthogonal projector for all tests.
The change from S195's k,q to created k,l reverses one momentum;
the spherical band is invariant under that reversal.

Let P=P_K^(2), Q=1-P. Orthogonality, not a generic triangle
estimate, gives

    <psi_D,psi_Gamma>-<Ppsi_D,Ppsi_Gamma>
    =<Qpsi_D,Qpsi_Gamma>.

Both cross terms vanish. For real tests, z=<psi_D,psi_Gamma>
has <[T[D],T[Gamma]]>=z-conjugate(z), so

    B = i(z-conjugate(z))/4 = -Im(z)/2;
    |B-B_K| <= ||Qpsi_D|| ||Qpsi_Gamma||/2
             <5e51 N[D]N[Gamma]/K.

This is stronger than estimating one discarded tail against a
full vector. It is a quantitative full-continuum weak bilinear
limit, not an assertion about the operator norm of T[f].
The norm of the complete vector gives |B|<5e49 N[D]N[Gamma].
