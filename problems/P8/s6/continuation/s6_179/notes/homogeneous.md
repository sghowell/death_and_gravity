# Complete homogeneous source, including its contact

For any smooth homogeneous metric and clock history sufficiently
close to the base and inside the same analytic domain, the full
covariant source of S6.174 is a temporal one-form S=S0(t)dt.
Its value need not vanish. Its exterior derivative nevertheless
vanishes, so the Proca equation (I+zeta delta d)W=S has the exact
compatible solution Wbar=S. The histories agree with the original
clock near the Cauchy slice, where S and the mean data vanish.

The actual additional classical action is

    kappa integral sqrt(-g) [-zeta F(W)^2/4+(W-S)^2/2].

On Wbar=S, both F and W-S are zero. Its first variation vanishes
for EVERY smooth compact metric or scalar test variation before
that test is restricted to the homogeneous sector. This retains
all implicit source derivatives, the S^2 contact and the temporal
constraint. Free coherent Proca stress alone would not vanish and
would be the wrong observable.

The conditional Gaussian stress splits into the ordinary connected
Proca stress for the same metric and this full classical mean
stress. Consequently on all admissible homogeneous histories,
not only to first order about the clock, the mean term is zero.
Its homogeneous first response is zero as well.

Homogeneous sources need not have finite spatial L2 norm. This
argument does not borrow S6.178's spatially integrated norm for such
sources. Smooth Cauchy uniqueness can be applied on local causal
diamonds, and a smooth coherent shift defines the corresponding
state on the local sourced algebra. Neither a global finite-energy
state vector nor Fock implementability is asserted.

For spatially inhomogeneous histories dS can be nonzero; S6.178's
separate causal source estimates remain relevant. No cancellation
outside the homogeneous domain is inferred here.
