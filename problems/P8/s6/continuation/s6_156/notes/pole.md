# Unit-disc nonlocal bound and finite parameter re-expansion

S6.145 establishes an integrated soft-tail bound E for
both direct fermionic quadratic primitives, holomorphic
on a neighborhood of |s-1|<=2. Its earlier reported
E/3 divided OS estimate used the half disc. Expand in
v=s-1 at radius two. The affine OS operation removes
orders zero and one, so for 0<rho<=1,

    |Pi_R(v)|/|v|^2 <= E/[4(1-rho/2)].

On the full unit disc the constant is E/2. The extension
uses the SAME proved holomorphic outer disc; it does not
relabel the half-disc theorem without a new estimate.

The complete fixed-hybrid-coordinate two-loop OS coefficient
is bounded by the sum of

    S6.154: complete scalar interaction-MS converted bound;
    E/2:   both direct fermionic primitive remainders;
    S6.136/S6.148: complete paired insertion remainder.

The last is uniform on Re(s)<=4, so it covers this disc.
All finite local mass/source and wave references are
paired and projected before the regulator is removed.

The first hybrid coordinate change contributes at order
two inside the first-loop OS kernel. With inverse convention
Pi1_R=Pi_scalar,1,R-f_fermion,1,R and
q1_D=-k_D E_Phi q, its finite value is

    -k0[2Pi_scalar,1,R-f_fermion,1,R].

The OS kernel is already holomorphic in epsilon, so here
its positive-epsilon parameter terms cannot multiply a
pole. Its extra bound is k_up(2B_scalar,1+B_fermion,1).
No second parameter shift changes the prescribed free
mass-one inverse. Parameter differentiation commutes with
the OS map because that physical mass is held fixed.

Thus the full canonical truncated inverse is

    D_[2](s)=v+h Pi1_R(s)+h^2 Pi2_R(s)
            =v[1+v H_[2](s)].

At h=1 the combined bound is below 10^-18, so the second
factor cannot vanish anywhere on the closed unit disc.
The only zero is v=0 and its derivative is one. The light
propagator therefore has mass one and residue one there.
The same conclusion holds for formal truncations evaluated
at real 0<=h<=1 using the corresponding absolute bound.

This is a statement about the full fixed-order inverse.
It is not a global propagator, an exact positive spectral
representation, a later-loop massless-cut statement or a
high-energy contour theorem.
