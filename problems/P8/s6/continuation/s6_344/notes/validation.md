# Verification contract

The21 manifested source files produce a deterministic20-field
read-only report. There are514 named exact checks,536 scalar entries,
42 proof gates, eight controls and670 rejected inputs. Module exports
and every relative import are checked before freezing. The complete
actual source manifests and raw hashes of all five direct inputs
are verified, not only a selected parent digest.

All symbolic computations in private cold, fresh-parent, native,
ordinary and CLI checks use the original SymPy backend. A completed
parent cache in a fresh process is disclosed separately from cold
timing. Source equality between private, fresh and repository copies
is checked before the one native request; all native fields and every
captured source byte are subsequently validated.

The written generic polynomial, analytic-origin and positive-integral
arguments are essential. Tests include the full divided-difference
identities, coincident limits, all three line insertions, independent
actual-mass kernels, endpoint primitives, equal-mass and heavy-mass
limits, and all24 label normalization. They do not formalize the
proof in a proof assistant or establish missing P8 hypotheses.

Mutations of any report field, missing/extra fields, changed original
frontiers, unsupported physical scopes, invalid masses, order labels
and line labels are rejected. Validation occurs before cache lookup
for the strict line/order API, so booleans or SymPy integers cannot
alias an already-cached valid Python integer call.

External ordinary tests, CLI and covering full-suite acceptance
receipts are kept outside this immutable manifest. No operational
status or future test result is retroactively written into it.
