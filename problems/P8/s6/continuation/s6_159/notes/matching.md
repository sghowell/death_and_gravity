# Full regulated first-source re-expression

The original H source has Phi weight zero as a bare
coefficient, but its first reference J1,D=-G T_D(1)/2
depends on the cubic interaction. Therefore it still
changes when G is re-expressed in the complete first
Phi field direction

    G_H,D=G-h k_D G+O(h^2),
    k_D=k0+epsilon k1+O(epsilon^2).

The bare H/source field itself is unchanged. Expanding

    h J1,D(G_H,D)+h^2 J2,H

at the original MS interaction boundary adds
k_D G T_D(1)/2 at order two. With the full first tadpole
of S6.158 its finite part is

    -G[k0(ell+1)+k1]/(2Q),   ell=log(mF^2).

The k1 term multiplies the pole of J1,D and cannot be
discarded. Using only the finite first source would
miss it. No second field normalization multiplies
a nonzero tree source; J0=0.

M1=mF1=0, and the physical/free Phi mass remains one.
There are consequently no further first determinant/
tadpole mass-coordinate changes in this direction.
The proper cubic counterterm is already an order-two
source occurrence; varying its parameters starts at
order three.

This completes the source map for the same named
Phi/vacuum observables as S6.156-S6.158. It is not an
external-fermion canonical dictionary or a composite
derivative-coordinate source dictionary. Those must
not be inferred from a constant H-source result.
