# Frozen physical sources

S326 provides the unchanged original parameters, full radiative
logarithmic coefficient and all open primitive/matching records.
S303 fixes the known minimal four-point hard reference with its
UV-before-IR convention and nu=1. It proves
|I_known|=|2Re(H4_known/A0)|<1e12/kappa. Unknown alpha,beta,
delta_kappa and other physical matching coordinates stay unassigned.
S304 supplies the full47-diagram one-real tree, exact recoil, physical
propagator gaps and uniform low/high-energy constants.

All three actual native SHA256 values are pinned in verify.py.
The native builder reconstructs each complete direct report and checks
whole equality; preflights check the direct raw hashes and source manifests.
No remembered or projected parent hash is treated as native evidence.

The fixed-Born extension S_lambda*h defines the selected subtraction
kernel. Its finite-recoil replacement, an independent five-point finite
hard remainder and detector-scheme matching are not supplied by this
definition. No undetermined coefficient is chosen for convenience.
