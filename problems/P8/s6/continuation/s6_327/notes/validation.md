# Acceptance boundary

Private cold and fresh-copy checks must use original SymPy. They check
all exact residuals, proof gates, original parameters, source bytes,
whole packet serialization, tests and actual frozen direct input hashes.
The fresh process reconstructs the immediate frozen parent's complete
own scientific packets before importing this successor; the successor
preflight forces them again, with within-process completed-parent
cache reuse explicitly disclosed. This is not an independent parent
reconstruction a second time in that same process.

Only after matching cold/fresh source hashes may the source set be
copied byte for byte into the repository and sent once to the native
helper. The helper reports the complete native JSON using its framed
ASCII protocol. Hash, manifest, all twenty fields, direct reports,
frontiers and counts must be validated before storing exact raw bytes.
No frozen source or raw report is reformatted afterward.

Native completion alone is not publication acceptance. An ordinary
original-SymPy test replay, separate read-only CLI and complete FULL
source replay must finish at C0 against captured bytes. The scoped
exact-GCD adapter is allowed only inside FULL and must restore the
original backend. Any completed-parent cache reuse is disclosed.
External assessments carry actual timing/count/hash receipts and
supersede no frozen scientific bytes. Failed draft attempts remain
external evidence; no failed or partial run becomes a pass.

The initial draft science run had446 passes and3 failures in the
independent unitary-frame test: the Python integer zero parameter
caused ordinary division to introduce floating-point entries. The
test now converts that parameter to an exact SymPy scalar and checks
that no Float enters the expression. No scientific formula, constant,
bound or residual was changed. Final-source cold/fresh and subsequent
native acceptance are required after this correction.
