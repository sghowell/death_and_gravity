# Evidence and immutable replay boundary

Written proofs give the full momentum/time and regulator estimates.
Exact SymPy residuals check their local identities, prefactors,
domain arithmetic, finite parts and scope. External continuum
results remain analytic inputs, not Lean-formalized theorems.

Independent tests use complete twenty-frame matrix products,
full-function Taylor jets already checked independently in S6.170,
finite-angle majorants, all radial intervals, nonzero-regulator
Gamma integrals, a fixed-comoving pressure derivative and independent
full lapse/log-scale variations. Both reduced and unreduced Euler
actions are checked. The finite pole-basis R^2 difference changes
the actual bounce energy and is a negative control.

Actual twenty-frame projectors are evaluated at4800 and5200 digits.
The final frequency increment and coupling and the relevant tiny
coherences are nonzero; relative refinement is better than1e-100.
The full mass profile and double-zero Newton anchor are checked
at850 digits, including a small but nonzero profile argument1e-180.
These numerical tests supplement the analytic bounds; they are not
outward-rounded validated integrations.

Before freeze, all own payloads must pass the unchanged exact
serializer; decimal diagnostics are strings, not SymPy Float.
The first local smoke probe exposed an unsimplified exact zero,
fixed privately without changing any bound. No scientific identity
or numerical envelope was weakened. Native, direct science,
ordinary and independent CLI use unmodified SymPy. The full suite
alone uses the separately audited exact GCD adapter.

The native JSON and every explicit source/proof/test file receive
SHA-256 guards. No report is generated by editing an earlier JSON.
Fresh repository science, ordinary, CLI and captured full-suite
results are required before publishing the claim; runtime evidence
belongs in the later root assessment, outside frozen source globs.
