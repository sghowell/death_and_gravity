# Canonical phase bridge beyond a single oscillator

Let \(J=\left(\begin{smallmatrix}0&1\\-1&0\end{smallmatrix}\right)\), \(v=(1,-i)^t/\sqrt2\), and let \(D,G\) be arbitrary real two-mode cross blocks. At the source time choose canonical coordinates in which each pure Gaussian covariance is \(I/2\); normalization of a pure mode permits this symplectic change of coordinates. Let \(U,V\) be the two independent real mode transports from source to detector.

The off-diagonal covariance tangent source is
\[
 S=(JG+GJ^t)/2.
\]
Both reverse mode blocks must be included. With the original current readout sign its cross-mode contribution is
\[
 -\operatorname{tr}(D^tUSV^t)
 =2\,\operatorname{Im}\left[
 \overline{v^tU^tDVv}\ (v^tGv)\right].
\]
This is elementary real \(2\)-by-\(2\) algebra: put \(B=U^tDV\), expand its four real entries and those of \(G\), and compare the two sides. The identity itself needs no equality between \(U\) and \(V\). The symbolic check uses independent symplectic transports and arbitrary cross blocks; the independent Fock tests also use unequal frequencies and time-dependent kinetic coefficients.

The factor two in this single distinct-mode cross-block identity is not an extra factor to append to the continuum formula. Reassembling the real-field ordered polarization pairs and the quadratic Hamiltonian's one-half factor gives precisely S195's original normalization. No independent duplicate quantum fields are introduced.

Write the annihilation coefficients as \(b_X=A_Xe^{-i\Theta}\). The current therefore uses \(\overline A_D A_G e^{+i(\Theta(t)-\Theta(s))}\) and positive imaginary part. Creation coefficients give the equivalent negative-imaginary, negative-phase formula. S198's integration-by-parts identity remains valid for that creation convention. The withdrawn S207/S212 identification used annihilation amplitudes with the creation phase.

For real \(d\) and real tensor data, the sharp operation conjugates the mode amplitude. For complex external Fourier tensors the established real bilinear coefficient is complexified linearly; one must not apply an antilinear imaginary-part operation to the entire external complex source. Similarly, continuation in \(d\) uses the two branches at the same parameter, as proved in the dimension note.

The unit-W8 reference family has the required algebraic mode normalization at each clock, but is not promoted to a new physical propagated state. The actual-state-minus-reference comparison remains explicit. The full second-metric contact is separate from this pair commutator.
