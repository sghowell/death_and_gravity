# Read-only acceptance contract

Seven modules, two test files and nine Markdown sources define the
scientific packet; the native report has twenty fields. Private, fresh
and repository scientific bytes and hashes must agree. The fresh run
forces the full immediate parent packets before its own residuals.

Exact checks cover the whole-D Laurent assembly, separate UV/IR
residues, physical completion, old and evanescent Gram terms, finite
soft division, complete crossing, mass dimensions and bound constants.
Independent physical contour integrals are combined with the unexpanded
D-dependent coefficients at decreasing epsilon to calibrate the finite
limit. Master cut/threshold values, all six physical crossings, extreme
spacelike windows and invalid-domain inputs are also tested.

Quadrature calibrations are not certified numerical error estimates.
The uniform claims rely on the written contour, endpoint and coefficient
proofs, whose exact algebra is separately checked.

After source freeze the native specification is sent once. Complete raw
chunks, source hashes, canonical REPORT AST, twenty fields, counts and
original frontiers are checked. Native, direct, ordinary and CLI retain
original SymPy; the exact-GCD adapter is FULL-only. Ordinary/CLI and full
captured regression must pass before publication.

Failed private probes and preflights are recorded in the external
assessment. Frozen sources and native reports are never rewritten.
