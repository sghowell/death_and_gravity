# P8 S6.318: uniform weighted temporal soft-current bound

This scoped successor bounds the unchanged complete pure-soft temporal
current at every finite multiplicity, uniformly over angular and nested
collinear configurations, with explicit soft-energy dependence.

The proof combines arbitrary Rosen geometry, a transverse/longitudinal
grading, the conserved temporal inverse and a labeled coefficient
majorant. Independent exact low-valence and complete four-ray tests
check the implementation and retain a failed unweighted control.

Read FORMULATION.md and notes/geometry.md, notes/grading.md and
notes/majorant.md. The native verifier is read-only.
