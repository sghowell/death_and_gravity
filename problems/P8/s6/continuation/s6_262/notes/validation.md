# Independent checks and immutable replay boundary

The scientific manifest has six package modules, two test modules,
README/FORMULATION and seven proof notes: 17 files. The report has
20 explicit fields, 50 named exact checks, 196 scalar entries,
31 gates, nine controls and 260 rejected inputs. Scalar-entry
counts do not count independent physical theorems.

Tests include full shifted four-metric and inverse comparisons,
direct scalar and full four-index Maxwell contractions, source-pinned
coefficient disagreements for the incorrect factor, lapse-dependent
ten-coordinate metric Jacobians, six families of clock jets through
fourth derivative, whole nonlinear source gradient/Hessian differences,
correct periodic physical-volume quadrature with both tensor profiles,
correlated Weyl cubature and unaliased three-direction Fourier checks.
Explicit tests demonstrate why generic volume cancellation did not
detect the wrong parent. Finite diagnostic data never replace the
physical action or preparation.

Private preflight must check all residuals, gates, schema, source
manifest, previous source/report hashes and serialization, plus every
science test, before freezing. Fresh repository execution repeats those
checks on exact copied bytes. Native original-SymPy construction
rebuilds all historical ancestry with protected scientific hashes and
transfers its raw ASCII report in acknowledged exact chunks.
Every private/repository/native source hash must agree.

The report builder is read-only. Ordinary tests and a separate CLI
replay use original SymPy. Only captured full P8 regression uses the
audited exact-GCD adapter, self-checks and immutable test snapshot.
At most one full regression and one ordinary/CLI pair run together.
A completion claim requires observed zero exit codes. No frozen file
is repaired after the fact; a subsequent correction requires another
explicit successor. Rebuilding S261 certifies reproducibility of the
historical evidence, not the refuted physical identification.

Actual run results, any development failures, native transfer and
publication evidence belong in the external assessment. Publication
uses a scoped exact manifest and independent remote hash check,
excluding unrelated P4/P9 changes. The finite tests are not a formal
proof of all written continuum and source-binding arguments.
