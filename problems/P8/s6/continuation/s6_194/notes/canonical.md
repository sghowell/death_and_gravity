# Clock rotation identity and both canonical chain factors

At gamma0 the common state is rotationally invariant, with two
equal transverse modes and the actual longitudinal mode. For a
unit momentum vector n and P=nn^t, the physical equal-time blocks
are C_A=cT(I-P)+cL P and C_pi=pT(I-P)+pL P.

For a tracefree symmetric detector D, direct contraction of the
full constrained physical Hamiltonian vertex with these blocks is

    -a m^2 [cT trD+(cL-cT)n^tDn]
    +cT k^2 [trD-n^tDn]/a
    +[pT trD+(pL-pT)n^tDn]/a.

This includes both longitudinal coefficients. The metric vertex
is block diagonal, so no A-pi covariance term enters this current.
The angular average n^tDn=trD/3 makes this expression zero.
Apply the identity first with finite rotational regulators, then
to the convergent fixed-prescription limit. It is not a formal
cancellation between unregulated divergent integrals. The local
covariant current is likewise isotropic. Thus J_tracefree(0)=0.

The canonical field is h=sqrt(kappa)gamma/2. If J_gamma is the
coordinate-density metric current, the canonical quantum force
is 2J_gamma/(a^3 sqrt(kappa)). Its linearization includes a second,
independent factor dgamma/dh from differentiating the current:

    delta force_h =4 DJ_gamma[delta h]/(a^3 kappa).

There are TWO factors2/sqrt(kappa), one from each variation;
a^3 is unchanged along the unimodular family. The complete first
current-direction bound1e95 and kappa1e800 therefore yield
the homogeneous C12-to-C0 linear response bound4e-705.

At the clock Gamma is arbitrary in the stated normalized smooth
prepared subspace; the first variation is linear. Scaling a
direction establishes the operator bound on that space. The
finite-amplitude estimate away from the clock is only along the
specified amplitude lines. Neither assertion is a general nonlinear
Frechet bound on an enlarged domain.

This is not the fully constraint-reduced scalar/mixed canonical
normalization, a complete quantum metric initial state, a same-space
contraction or a response inverse. A C12-to-C0 estimate loses
derivatives. Combining it with a two-derivative classical Green
operator does not by itself close a fixed-point argument. No
higher-derivative solution or pole has been removed.
