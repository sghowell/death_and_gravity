# S6.334: dimensionally complete selected gravity-radiation tree

Original V/G/B/P8 remain OPEN; scoped P8(a) is unchanged.

The original complete47-graph tree now has a consistent D-dimensional
gravity sector. Both the propagator trace coefficient and closed metric
loops are continued. The gravity correction is exactly
2mu^2*epsilon/(1+epsilon) times a named auxiliary tensor; no particle,
mass, coupling or matching value is changed.

The full polarization sew, including all matter-gravity interference,
is cubic in epsilon/(1+epsilon). It retains a trace contribution that
cannot be recovered from the two four-dimensional helicities and has
an explicit pointwise regulator-rate bound. It is not yet an integrated
real-minus-soft or finite hard-loop matching result.
