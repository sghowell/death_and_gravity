# Immutable scientific inputs and replay boundary

The scientific manifest contains six package modules, two test modules,
README/FORMULATION and seven proof notes: 17 files. The report has 20
explicit top-level fields. The final exact packet counts are 50 named
checks, 93 scalar entries, 32 gates, nine controls and 262 rejected inputs.
A scalar-entry count is not a count of independent physical theorems.

The tests include complete packet replay, all unsupported-input
rejections, an independently integrated inverse periodic gauge map and
its entire 3x3 metric, exact periodic mean derivatives, unaliased
three-direction Fourier sampling, whole correlated Gaussian cubature,
Fock vacuum commutators and full noncommuting matrix symbol comparisons.
Comparison fixtures do not replace the original physical preparation.

The complete private preflight checks every exact residual, gate,
manifest entry, field schema, parent hash, serialization and every science
test before freezing. A separate fresh repository process repeats these
checks on the copied bytes. The native original-SymPy process rebuilds
the full ancestry, captures all immutable scientific inputs before and
after construction, and transfers the raw report in acknowledged exact
chunks. All private, repository and report-listed scientific hashes
must agree. No source or predecessor is repaired after freezing.

The report builder never writes a report. Every field, missing/extra
field and complete byte-derived source manifest is checked by read-only
replay. Ordinary package tests and an independent CLI replay use original
SymPy. The captured all-P8 regression alone uses the audited exact-GCD
adapter, its original-path comparison self-checks and immutable test
manifest. Only one full regression and one ordinary/CLI pair run at a
time. Completion requires observed zero exit statuses, not progress
percentages or a running-session assumption.

Exact run results, native transfer evidence, development failures if any,
and publication details belong in the external assessment after
validation. Publication uses an exact scoped manifest and independent
remote-hash confirmation, excluding unrelated P4/P9 work. The written
local gauge, reference symbol and asymptotic arguments are not claimed
formally verified by the finite tests.
