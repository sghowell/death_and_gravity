# Conditional mass derivatives and the failed naive-map screen

For an arbitrary real scalar argument z(t), let
|z_dot|<=v and |z_ddot|<=a. The profile estimates imply

    |mass_dot| <= |y|v,
    |mass_ddot| <= |y|(a+9v^2/R).

Divide by the squared/cubed global lower mass 0.99mF
to obtain the explicitly conditional ratios in the report.

As a DIAGNOSTIC only, insert z(t)=sqrt(kappa)t,
kappa=10^800. The actual bound |y|<3e-103 gives

    |mass_dot|/mass^2 <3.061e-103 <1e-102,
    |mass_ddot|/mass^3 <2.783e-202 <1e-201.

This argument is not automatically the polynomial
parent field after the derivative map. Even on flat
space, insert Psi=sqrt(kappa)t into the literal full
cubic map of S6.111. With Phi denoting the value of
Psi on that test jet, the result is

    F=[1+2lambda kappa-2gamma kappa] Phi
      +[lambda-2gamma/3-c/6] Phi^3.

Here c=4lambda^2/gamma. The linear coefficient is of
order 2e200 at the actual parameters. At t=0 the
saturating profile has f'_R(0)=1 and both masses
are mF. The same positive GY14 ray gives
|y|>2e-103, so the first mass-derivative ratio for
this naively extrapolated map is strictly above

    (2e-103)[1+2lambda kappa-2gamma kappa]
       sqrt(kappa)/mF^2 >1e97.

Thus the small ratios for the direct argument cannot
be transferred to this cubic-map extrapolation.
This fails a small-derivative mass-expansion screen.
It is not a particle-production lower bound, a
proof that the exact Dirac evolution fails, an
actual curved-bounce calculation or a whole-row
exclusion. The original map was only controlled
on a restricted vacuum function class.
