two test files and nine Markdown files. The native report has twenty
fields. Source hashes,395 named residuals/449 scalar entries,110 proof gates,
all8 controls,73 rejected inputs,9 original primitive statuses,

full434/regular387 amplitude pairs at the original huge hierarchy.

assignment and the common hard/light propagator inequalities.

are exact integers or rationals and derive from full component sums.
No sampled maximum is used to infer a uniform statement.

Before freezing: lint/format only these unfrozen private files; run a
cold whole-source/science preflight; copy all eighteen exact files
to an independent fresh private directory and force the entire
immediate parent packet before its own preflight; compare private,
fresh and repository bytes and hashes. Then native buffered capture
must protect all earlier frozen sources and raw reports. A native
raw report is copied byte-exactly and checked against source manifests
and the twenty-field builder AST. Native/direct/ordinary/CLI keep
original SymPy; the separately audited exact-GCD adapter is FULL-only.

Ordinary native equality, CLI replay and captured full-P8 regression
are separate acceptance steps. Their actual commands, counts, source
capture and exits belong in the external assessment after they finish.
The scientific report does not pretend those external runs already
completed. Never repair a frozen source to fit a later replay.
