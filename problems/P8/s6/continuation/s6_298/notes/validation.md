# Immutable validation protocol

Before freezing, require original-SymPy cold preflight and a fresh copy
that first builds the complete immediate-parent packets. Check all exact
residuals, source hashes, ASCII/newlines, module exports, AST report fields,
exact serialized payloads, all scope guards and independent science tests.
Compare private/fresh/repository sources byte for byte.

The persistent native helper accepts the new specification once. Capture
all raw chunks, check offsets/lengths/acknowledgments and the native SHA,
then copy bytes unchanged to the frozen AST's canonical REPORT location.
Check raw/source/hash/field/count/frontier contracts in both locations.
Never edit scientific sources or raw reports after that freeze.

Acceptance additionally requires an original-SymPy ordinary test run,
independent read-only CLI and complete captured P8 regression. The exact
GCD adapter is FULL-only. Run at most one FULL and one ordinary/CLI pair.
Completed validation outcomes and any corrections belong in a separate
external assessment, never in this frozen scientific packet.

Private research initially needed rational cancellation before a formal
J-pole limit, and a probe needed boolean normalization for exact SymPy
inequalities. Neither changes a physical formula. The complete final
outcomes must be recorded before publication; pending runs are not passes.
