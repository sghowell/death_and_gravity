# Validation boundary and immutable replay

The mathematical operator, compactness, elliptic, analytic
continuation and implicit-function arguments are written proofs,
not formally verified theorems. Exact symbolic identities check
the complete source bindings, time contacts, full covariance
heat identities, every displayed finite tail term and independent
time-ordered matrix diagnostics. Numerical matrix ODE and Gaussian
quadrature tests are independent diagnostics, not a simulation
of the full original P8 Hamiltonian.

The first unfrozen localization probe exhausted SymPy's recursive
positivity inference on a degree255 polynomial times an
exponential. Factoring out the exponential and testing the
complete polynomial identity avoids that inference without
dropping any term or weakening the equality. The corrected
exact coherent/ordering/localization probe passed.

All native, direct, ordinary and CLI validation uses original
SymPy. Only the separately captured full regression may use
the audited exact-GCD adapter, with its original-path selfchecks.
Source hashes cover every source, test and written-proof file.
The raw native report must match its native/private/repository
source manifest and every AST-derived report field. Frozen
ancestor bytes and all historical qualification/refutation rows
remain untouched.

Final private/fresh, native transfer, ordinary/CLI and captured
full-regression observations belong in the external assessment,
after observed zero exits. No estimated test count or an
unfinished process is treated as a successful replay.
