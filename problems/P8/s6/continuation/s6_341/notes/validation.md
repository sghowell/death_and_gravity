# Read-only validation contract

The package has a complete source manifest and twenty report fields.
The independent cold preflight checks exported symbols, every exact residual,
all proof gates, original source parameters, invalid-input rejection and the
science tests with the original SymPy backend.
The fresh preflight first warms the frozen immediate parent's complete
packets, then receives one START only after exact final source copying.
That ancestor cache reuse must be disclosed.

The native process receives one frozen specification. Every complete chunk
is validated before its continuation ACK, with no final ACK. Report
equality checks all twenty fields, exact source hashes, counts and all
direct input provenance. Ordinary tests, all five CLI replays in a batch,
and the covering full P8 suite remain separate acceptance gates.
Operational timing or acceptance receipts are external to this immutable
scientific source manifest; no later receipt silently changes these files.
