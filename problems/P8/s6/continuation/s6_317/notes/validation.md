# Independent validation and publication boundary

Eighteen ASCII, newline-terminated sources comprise seven modules,
two test files and nine Markdown files. The native report has twenty
fields. Exact scientific payloads contain no floating-point values.
The unfrozen count pass found 477 named residuals covering 1,344 scalar
entries, 101 proof gates, 8 controls and 73 rejected inputs. All 173
matching records, 9 primitive obligations and 6 historical qualifications
are retained. Both cold and fresh preflights check these exact counts.
Initial style checks reported six import-order/unused-binding issues;
all were corrected before preflight without changing any assertion.

The new exact formal-array validator deliberately differs from the
frozen numeric point API: symbolic rational functions in explicitly
real variables are accepted, while floats, nonfinite expressions and
unspecified-real symbols are rejected. The existing numeric API is
untouched. Positive-energy and additive-momentum checks protect the
finite coordinate construction.

Independent routes include a literal nilpotent pullback, the closed
degree-three nonlinear formula, recursive projected propagation and
the complete original-gauge5116-tree amplitude. The four-leaf chart
checks every nonempty subset, not only the top coefficient or its
temporal components. The full conserved-source propagator decomposition
is checked as a symbolic matrix identity.

All24 frozen conserved-pair coefficients are compared directly with
temporal matrix entries. All8 planar TT triples are computed exactly.
Their denominator factorizations, numerator supports and coefficient-l1
budgets establish the bound over the continuous box; finite collinear
limits alone do not supply that estimate.

The linear-only projection has a deliberately retained nonzero pole.
Additional rejection tests detect a missing quadratic numerator zero,
a remaining angular denominator, invalid chart data and unsupported
scope promotions. The public original/diagnostic selector validates
its Boolean input before caching, retaining the lesson of the
immediate parent's interface correction.

Private exploratory probes also checked unequal-energy pair endpoints
and a simultaneous-collinear family. These directional tests informed
the next bound but are not used as a proof of arbitrary-angle control.

Cold and independent fresh-root preflights check module exports, exact
counts, proof gates, float-free serialization and every science test.
The fresh run forces the entire immediate parent's packets first.
Exact private/fresh/repository comparison precedes source freeze.
The native helper receives one specification and only complete-chunk
acknowledgments. Raw/source hashes, the twenty-field REPORT AST and
all original frontiers must pass before the raw report is frozen.

Original-SymPy own ordinary/CLI and the complete captured P8 regression
are subsequent publication requirements. Their eventual outcomes
belong in the external assessment, not retroactively in frozen sources.
The exact-GCD adapter is FULL-only; native/direct/private/ordinary/CLI
retain original SymPy. At most one FULL and one own pair run at once.
No resource diagnostics, blind retries or changed numerical tolerances
are used. Original V/G/B/P8 remain OPEN.
