# Finite radiative angular soft conversion

This scoped successor to S300 supplies the first dimensional angular
derivative that S300 explicitly left open. Its fixed-ball representation
retains the evanescent trace term and has a uniform, integrable collinear
quarter-power bound with no particle-count cutoff.

On the unchanged compact radiative domain, |Delta_sigma|<2000/kappa.
A fixed-resolution regulator error is explicit. The known unexpanded
detector reference differs from its elastic counterpart by less than
4250/kappa at original parameters.

Read FORMULATION.md and notes/angular.md, notes/bounds.md and
notes/conversion.md for the scheme, analytic proof and exact scope.
Finite/evanescent hard amplitudes, complete nonleading radiation,
physical analytic/Regge bounds and original V/G/B/P8 remain OPEN.
Scoped P8(a) and all frozen ancestors are unchanged.

Native, direct, ordinary and CLI use original SymPy. The guarded
exact-GCD adapter is reserved for complete snapshot regression.
