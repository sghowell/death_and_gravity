# Read-only acceptance contract

Seven modules, two test files and nine Markdown sources define the
scientific packet. Its native report has twenty fields. Cold/fresh
manifests and repository copies must match exactly; the fresh run
forces complete parent packets before its own residuals.

Exact generic conserved tensors, an actual recoiled state, beta moments,
logarithmic integrals and all majorant constants are checked. Independent
massive Feynman-parameter formulas and full-radiative fixed-ball
quadratures calibrate the finite derivative and regulator limit.
Collinear splitting, bounded exceptional representatives, zero-angle
zero-radiation endpoints and domain rejections are tested.

The specification is sent to the native helper once, after source
freeze. Complete raw chunks, source hashes, canonical REPORT AST,
counts, original frontiers and every report field are checked.
Native, direct, ordinary and CLI retain original SymPy; only the FULL
snapshot uses the audited exact-GCD adapter. Ordinary/CLI and full
captured regression must pass before publication. Private/native
success alone is not acceptance.

Failed research/preflight attempts and final outcomes are recorded
in the external assessment without editing frozen scientific sources.
