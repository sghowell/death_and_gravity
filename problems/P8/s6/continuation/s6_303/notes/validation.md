# Read-only acceptance contract

Seven modules, two test files and nine Markdown sources define the
scientific packet; the native certificate has twenty fields.
Cold/fresh/repository sources and manifests must match exactly.
The fresh preflight forces the entire immediate parent's packets.

Exact checks cover the full finite phase, both real forward
coefficients, complete massive-block cancellation, all rational
coefficient derivative norms, master derivative signs/zero jets,
termwise budgets and the positive Born/endpoint identities.
Independent complete-master quadratures calibrate the phase,
classical/logarithmic coefficients, explicit triangle remainder
and the real rate in both near and interior regions.
Domain tests include arbitrarily small exact positive transfers,
so no hidden angular window is introduced.

These numerical calibrations are not certified quadrature error
bounds. The uniform result uses the written analytic estimates.

After source freeze send the native specification once, preserve all
raw chunks and verify hashes, canonical REPORT AST, all twenty
fields, counts and original frontiers. Original SymPy is used for
native, direct, ordinary and CLI; the exact-GCD adapter is FULL-only.
Ordinary/CLI and complete captured regression are required before
publication. Failed private attempts belong in the external
assessment, not revisions to frozen scientific sources.
