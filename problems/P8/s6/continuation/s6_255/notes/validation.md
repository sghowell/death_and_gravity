Private source/field preflight and science precede freezing. Native and
fresh repository hashes must agree before publication. The raw ASCII/LF
native JSON is transferred using verified chunk offsets, lengths and its
complete end marker; it is never parsed and reserialized by JavaScript.
The full SHA and every native/private/repository source hash and all20

discarded and replayed rather than treated as successful evidence.

Native, direct, ordinary and CLI use original SymPy; only the complete
captured P8 regression uses the audited exact-GCD adapter. Only one full
regression runs at a time. A shared snapshot counts for this checkpoint
only if it actually captured these frozen test files and checked their
collection completeness and unchanged hashes.

Actual gate counts, durations, snapshot hashes, transfer and publication
evidence are recorded in the external assessment, not inserted by editing
frozen scientific bytes. Commit/push uses an explicit21-file manifest,
staged source/report hashes and an independent remote check, preserving
unrelated P4/P9 changes. Original P8 is not closed by these scoped results.
