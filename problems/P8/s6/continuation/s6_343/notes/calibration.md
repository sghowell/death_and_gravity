# Independent exact calibrations

Use the three original S304 recoil states without changing n,g,C,kappa.
For each state and both physical graviton polarizations, contract the
literal256-component linear curvature against all21 unordered pair-pair
products. Compare those126 values against the independent transverse
v_ij dyads. Verify original scalar mass shells, nullness and exact
momentum conservation. All six canonical polarized contact amplitudes
are nonzero.

These checks fix conventions and exclude a physically empty basis.
Completeness comes from generic index counting and exact full256-word
Bose identities, not a sample rank estimate. In particular no massless
scalar approximation is taken. The generic polynomial variables obey
only necessary conservation/TT conditions, so their rank gives a valid
upper bound before imposing additional physical Gram relations.

The selected-pole checks recompute exact-D literal local, mixed,
factorized-bubble and quadratic identities from their pinned sources.
Finite Gamma values and all pole extractions use exact symbolic algebra.
No tolerance, numerical regulator fit or low-energy expansion inside an
ultraviolet loop is used.
