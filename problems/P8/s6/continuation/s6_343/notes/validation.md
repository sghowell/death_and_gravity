# Validation contract

Recompute the complete generic Bose polynomial identities, every null-TT
trace and k-slot, all original-state literal curvature contractions, the
strict whole-polynomial matching controls and the selected exact-D pole
inventory. Inexact payloads and unsupported scopes are rejected.

The certificate has twenty fields. Read-only validation compares all
fields, all named scalar or matrix residuals, the original source
manifest, every proof gate, controls, all nine primitive records, the
full matching frontier and six historical qualifications.
Mutation tests cover every field as well as missing and extra fields.

Cold and separate-copy science checks precede freezing. Native report
generation retains original SymPy. Ordinary tests and the CLI compare
the full frozen artifact with fresh read-only rebuilds. The repository
FULL adapter is separately audited and does not authorize changing an
identity, source, artifact or omitted scope.

A written finite derivative-order completeness proof remains necessary;
this is certificate-backed symbolic research, not a proof-assistant
formalization of a full quantum gravitational theory.
