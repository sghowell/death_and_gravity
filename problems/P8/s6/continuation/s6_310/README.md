# Complete selected two-graviton formal tree

The original four-scalar/two-graviton tree is constructed with all 434
labeled topologies: 38 quartic-contact, 198 heavy-exchange and 198
pure-Einstein graphs. A root-cut recursion uses the full canonical
metric jets, including the new scalar third-metric and Einstein
quartic vertices.

Independent action expansions, graph-count generating functions,
the frozen four- and five-point amplitudes, both-graviton Ward and
Bose checks, and exact original-parameter soft families calibrate the
implementation. The hierarchical soft current includes the already
emitted graviton; dropping that null leg fails the check.

This finite formal tree does not bound the integrated two-real
nonleading correction or the full all-N detector rate. Original
V/G/B/P8 remain OPEN, scoped P8(a) and all frozen ancestors unchanged.
