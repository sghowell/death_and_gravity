# Read-only validation contract

The packet consists of seven modules, two test files and nine Markdown
sources, with a twenty-field native report. Cold and fresh source
manifests must agree. The fresh run forces complete parent packets
before constructing this packet to detect mutable-ancestry dependence.

Independent probes include nine one-radiation states and ten states
withN1,2,3,5,20, full physical TT angular quadrature, exact recoil
shell/conservation checks, massless pair limits, Lorentz boosts and
arbitrary collinear splits. Exact zero-angle/zero-radiation endpoints
and invalid-domain inputs are included in the science regression.

All scientific payloads and residuals are exact. Numerical quadrature
is calibration, not proof of a uniform bound. The native specification
is sent once after source freeze. Complete raw chunks, exact bytes,
canonical REPORT AST, all counts, source hashes and original
frontiers are checked without regenerating the native report.

Native, direct, ordinary and CLI retain original SymPy. Only the
complete P8 snapshot regression uses the audited exact-GCD adapter.
Acceptance requires the ordinary/CLI and full captured regression;
private or native success alone is not certification.
External assessments record failed attempts and final acceptance.
