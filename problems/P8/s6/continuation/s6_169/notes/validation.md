# Independent checks and frozen reports

Exact algebra checks the physical pressure matrix,
the complete four-frame x component, the exact q1
connection/frequency relation, both UV pressure
coefficients, all dimensional pole/finite terms,
the local improvement and complete radial factors.

Independent tests use direct Pauli rotations and
projectors, finite-angle inequalities, full radial
quadratures at nonzero regulator, finite gamma
limits with and without the dimensional isotropic
factor, full profile derivatives and the restored
local improvement. Actual-parameter rational bounds
retain all terms and fixed mass-reference data.

Zero profile variation, momentum/source scope and
explicit invalid inputs are controlled. All own
payloads pass the unchanged exact serializer before
freeze; diagnostic decimal values are strings.

Private science precedes source freeze. Native
report, ordinary replay, direct science and CLI
use unmodified SymPy. Only the separately audited
full captured regression uses its exact GCD adapter.
The report pins every source/proof/test byte.

These checks supplement written analytic proofs;
they are not validated numerical integration,
formalization or independent peer review.
