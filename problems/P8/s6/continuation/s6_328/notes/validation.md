# Source and replay boundary

Cold and fresh-copy science checks use original SymPy and pin the
actual three frozen direct reports and their source manifests.
They certify every residual and proof gate, counts, exact payloads,
tests, original parameters and source hashes. The fresh process
reconstructs the immediate frozen parent's complete own science
packets before importing the successor, and explicitly discloses
completed-parent cache reuse in its successor preflight.

Only equal final cold/fresh source hashes permit an exact repository
copy and one native-helper submission. Complete framed raw bytes,
SHA256, all twenty report fields, source set, counts, direct-parent
reports and full frontiers must validate. Frozen sources and native
raw are thereafter immutable. Publication additionally requires
ordinary tests, separate read-only CLI and FULL source replay at C0.
Only FULL may use the scoped exact-GCD adapter, restoring it afterward.

An initial private rewrite probe left a mathematically zero sum of
positive-rational logarithms unevaluated; exact prime-log normalization
resolved it without changing the formula. Draft lint caught a
late-bound calibration lambda and a generated self-import in verify;
both were corrected before acceptance. Failed draft/harness receipts
remain external, and a partial run is never a pass.
