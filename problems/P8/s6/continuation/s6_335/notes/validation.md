# Independent checks and immutable evidence

Private exact probes verify the general-D Born correction and leading
soft residue, the actual auxiliary tensor remainder, the trace-completing
embedding, every D6 component budget, both energy windows and the actual
S296 phase normalization. The first low probe passed30 exact checks
and52 positivity gates with78 protected inputs unchanged.

A separate full-resolution extension replays that diagnostic, then
adds six high-energy recoil states including near-forward and backward
angles. Its combined33 exact checks and130 positivity gates passed,
with80 protected inputs unchanged. The high extension completed in
0.7335868329973891s after the preceding2.529960541985929s low replay.
These are private diagnostic timings, not publication acceptance.

The package's ten exact recoil configurations retain the original
n,g,C,kappa throughout. They test formulas and budgets; they do not
replace the written uniform action bounds and dominated-convergence
proof. Both light-cone gauge completion and the metric trace response
are explicit; no noninteger helicity count or four-dimensional-only
trace inference is used.

Cold and independently started fresh reconstructions use original
SymPy. The fresh process first rebuilds the complete frozen immediate
parent packets, then waits for one START after byte-exact final source
copying. Completed ancestor-cache reuse is disclosed. Preflight checks
actual parent raw/source hashes, source-set/20-field AST/export equality,
exact residuals, proof gates, API guards and unchanged source bytes.

Only matched cold/fresh hashes authorize the repository copy and one
native specification. Complete native raw bytes, manifests and inherited
frontiers must validate. Ordinary tests, a separate read-only CLI and a
covering FULL source regression must also finish C0 before publication.
Only FULL may use the audited exact-GCD adapter and it must restore the
original backend. Frozen evidence is not rewritten to hide failures.
The result is written analysis plus exact algebra, not kernel formalization.
