# Clock contact exactly once and output-density normalization

Start from the physical scalar ADM response R_ADM on(n,zeta,b), with the complete S214/S215 ADM chart already included. The actual clock metric has

This equals S220's3a³ pressure_ref(8delta²-6delta)nD nG/2.

Define Rhat=R_ADM+Kclock in the nn slot before the first-jet clock pullback. Since the first clock coordinate is n unchanged, Aclock^T Rhat Aclock gives the full clock response and includes this extra contact exactly once. The nonzero Gaussian one-point current is not erased by the cancellation with the fixed classical profile. An independent local functional with nonzero linear current checks the complete nonlinear clock composition and detects both omission and duplication.

The coefficient action was divided by the fixed reference density kappa a³. Accordingly normalize the Gaussian OUTPUT current by W(t)=1/(kappa a(t)³), defining Qbar=W Rhat. This factor commutes with the same-time clock matrix Aclock, not with a retarded source-time kernel. W Rhat and Rhat W are different operators in general; the independent two-time fixture makes this difference nonzero.
