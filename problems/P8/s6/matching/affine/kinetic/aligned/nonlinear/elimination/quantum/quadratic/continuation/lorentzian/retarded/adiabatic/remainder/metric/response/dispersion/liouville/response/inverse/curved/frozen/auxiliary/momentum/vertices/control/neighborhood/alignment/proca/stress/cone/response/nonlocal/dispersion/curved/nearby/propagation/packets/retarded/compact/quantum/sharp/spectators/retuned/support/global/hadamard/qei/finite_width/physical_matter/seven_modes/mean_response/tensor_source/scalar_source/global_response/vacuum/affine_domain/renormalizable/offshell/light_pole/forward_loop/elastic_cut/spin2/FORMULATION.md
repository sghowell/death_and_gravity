# One specified finite-gravity matter-vertex calculation

Take the exact canonical polynomial vacuum of S6.110 and its S6.112
mass-one, unit-residue light scheme. Add the minimal Einstein coupling
in that same metric. This is a stated extension of the polynomial
model, not an identification with the affine bounce or the derivative
field map.

Fix gravitational normalization operationally by the positive tensor
propagator iP/(q^2+i0), matter vertex -i T_mu_nu/M_Pl and
P_mu_nu,rho_sigma=(eta_mu_rho eta_nu_sigma+eta_mu_sigma eta_nu_rho
-eta_mu_nu eta_rho_sigma)/2. Thus t-channel exchange is
-[T1.T2-(Tr T1)(Tr T2)/2]/(M_Pl^2 t). This fixes any curvature-sign
convention ambiguity in the label Einstein coupling.

Compute the on-shell spin-two form factor of the light scalar,
T_mu_nu=2P_mu P_nu F(t)+(q_mu q_nu-eta_mu_nu t)D(t)/2,
where P=(p+p')/2, q=p'-p, p^2=p'^2=1.
The target is F(t) through one **matter** loop and its derivative at zero.
Use a covariant regulator for tensor projection before removing it.

Retain both stress placements in the mixed light-heavy loop and the
same fixed kinetic counterterm. Derive the canonical stress, triangle
parameter denominators, numerator weights and charge normalization
before using the result to compute the t-channel coefficient.

At fixed negative t subtract the tree graviton pole, then take t->0-
with an explicit remainder estimate. Keep only the one-loop coefficient
of F(t)^2, not its uncontrolled squared one-loop resummation.
No all-channel gravity, pure-graviton loop or Regge bound is inferred.
