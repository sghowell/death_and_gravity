# Coupled physical spatial momentum reduction

See [FORMULATION.md](FORMULATION.md). The actual matter and
vector momentum generators are included in a finite
flat-York recursion, and the resulting physical quadratic
Hamiltonian is compared with the prior model.

The intended read-only report entry point is
`python -m p8_coupled_momentum.verify --check`,
with every frozen P8 source root on the import path.

This is a finite physical-reduction prerequisite, not an
interacting cutoff or a quantum stability result.
