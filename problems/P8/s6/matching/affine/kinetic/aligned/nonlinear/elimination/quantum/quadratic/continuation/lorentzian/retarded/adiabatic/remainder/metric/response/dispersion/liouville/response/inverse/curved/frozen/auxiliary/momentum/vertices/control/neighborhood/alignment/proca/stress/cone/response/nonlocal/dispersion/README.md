# Isolated rank-one massive Proca range inverse

The new physical two-source reference block is diag(0,F), not an invertible two-by-two block. Its scalar factor F=-H has threshold H=16/15 and a zero-free first sheet. The exact positive inverse cut density has static moment 1/4.

The inverse 1/F has no instantaneous delta term. Its retarded kernel is integrable on the positive half-line, with small-time behavior O(1/[t log(1/t)^2]) and large-time behavior O(t^-3/2). The scalar C0 inverse norm on shrinking windows tends to zero. The lapse complement is still missing from this inverse.
