# Primary normalization and inherited proofs

The real-scalar vacuum normalization uses Martin (3.2):
[primary paper](https://arxiv.org/pdf/hep-ph/0111209),
[DOI](https://doi.org/10.1103/PhysRevD.65.116003).
The other normalization inputs are the frozen S6.112,
S6.113, S6.125 and S6.131-S6.132 derivations.

The finite bare-coupling conversion, independent
counterterm comparison, combined local ledger and
signed error intervals are derived here. No external
UV-completion, high-energy, naturalness or global
stability theorem is imported. These are written
proofs with exact finite regression checks, not
proof-assistant formalized or peer reviewed results.
