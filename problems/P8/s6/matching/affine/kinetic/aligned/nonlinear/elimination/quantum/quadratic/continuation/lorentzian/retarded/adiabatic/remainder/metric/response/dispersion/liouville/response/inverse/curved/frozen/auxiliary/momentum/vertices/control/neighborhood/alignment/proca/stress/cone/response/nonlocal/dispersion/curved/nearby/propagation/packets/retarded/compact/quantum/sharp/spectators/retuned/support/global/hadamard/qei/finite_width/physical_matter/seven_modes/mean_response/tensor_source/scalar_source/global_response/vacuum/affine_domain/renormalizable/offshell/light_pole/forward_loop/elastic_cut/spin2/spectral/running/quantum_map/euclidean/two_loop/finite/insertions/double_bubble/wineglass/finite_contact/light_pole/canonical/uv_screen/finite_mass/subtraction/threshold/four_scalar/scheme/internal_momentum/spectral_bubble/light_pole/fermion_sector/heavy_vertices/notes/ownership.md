# The complete paired family, not another local subset

The frozen S6.137 master expansion contains
+(1/2)Tr[D W2 D W2 D F0]. Pair F0 with its complete
physical on-shell reference first and set P=-D F0,R D.
This is the covariance variation of the complete scalar
one-loop quartic functional -Tr[D W2 D W2]/4.

The full W2 comes directly from the actual Gaussian
elimination of H, as checked in S6.113. It is not
replaced by its local L component. The literal variation is

    -(1/4)Tr[P W2 D W2 + D W2 P W2].

Four background derivatives distribute two legs to each
W2. The arbitrary-index formula gives three channels,
two insertion positions and coefficient one half for
each position. The code independently differentiates
the actual two-site Hessian for all five independent
fourth derivatives. No operator factors are commuted.

For a channel z the vertex at each end is

    C(z)+g(h1+h2),  C(z)=-L+g/(M-z),

where h1,h2 are the two internal nonlocal heavy
propagators. Multiplying the two complete vertices
gives one C^2 bubble, four Cg triangles and four g^2
boxes. Repeated heavy routes are retained; the
t-channel vertices need not be identical. Both light
insertion positions are bounded, each with its one-half
coefficient. Their combined bound is one copy per
channel, not an extra factor two.

Replace the marked light propagator using S6.135's
positive first-insertion spectral density. This
changes one internal mass squared from one to v;
it does not alter the external mass-one kinematics,
vertices, routes or combinatoric factors. This is
still a formal order-two contribution, not a resummed
propagator or the complete two-loop amplitude.
