# Convergent slope, uniform remainder and spacelike sign

The mixed-mass parameter denominator obeys the same derivative
majorants as the preceding spectral bubble:

    |B'(s;u)|<=1/[2(u-4)],
    |B''(s;u)|<=1/[3(u-4)^2].

Use w(u)<=4C/u, C=2NY/Q, and u-4>=u/2 for u>=T>=16.
The first derivative has the integrable spectral majorant
4C/u^2. Thus the finite outer slope satisfies

    0 <= r_spec=Pi_spec'(1) <= 4 C g/(Q T).

The second derivative is bounded by (g/Q)16C/(3u^3)
before integration. Taylor's exact integral remainder contributes
a factor one half, giving

    |Pi_spec,R(s)| <= B_spec |s-1|^2,
    B_spec=4 C g/(3Q T^2)=N Y g/(6Q^2 mF^4).

This is uniform on Re(s)<=4: the segment from one to s stays
inside that domain. Parameter and spectral majorants justify
differentiation, integration and analytic continuation on
compact subsets, with the displayed uniform bound.

For s=-t, d=t+1, the exact parameter remainder is
d b-log(1+d b). Its derivative is nonnegative and its zero
anchor is zero. It lies between zero and d b. Consequently

    0 <= Pi_spec,R(-t) <= (t+1) r_spec.

The slope and spacelike remainder are strictly positive when
Y and g are nonzero; zero couplings do not give strict positivity.
At the actual parameters the rational slope upper bound is
below 10^-616 and B_spec below 10^-1017. These bounds concern
the named covariance-insertion sector, not all two-loop terms.
