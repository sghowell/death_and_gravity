# Two distinct conditional common-parent error gates

The preceding construction concerns the exact classical
action. It does not itself give a UV completion or exclusion.
It does identify a quantitative comparison target.

For any proposed parent response on the same actual
background, with the same physical metric, local relational
observable and source/detector normalization, split its
paired response using the same source projectors:

    C_parent,low=<f,G_parent P_{k<=Lambda}J>,
    C_parent,high=<f,G_parent P_{k>Lambda}J>.

This split is an algebraic identity even if the parent
operator does not commute with the spatial projection.
Only the classical Fourier bound used homogeneity.

Suppose the parent response vanishes for the original
compact matter-spacelike supports. If it also satisfies

    |C_parent,low-C_classical,low|<=D/8,
    |C_parent,high|<=D/8,

then the lower classical band contribution D/2 gives

    |C_parent,full| >= D/2-D/8-D/8=D/4>0,

a contradiction. The same triangle argument permits any
nonnegative relative error fractions whose sum is below
one half. matching.py checks exact rational budgets and
rejects zero-margin, negative and non-exact inputs.

Neither parent error inequality is proved here. The
low-band inequality must include the actual parent state
and response, canonical/observable maps, background
matching, temporal-frequency validity, omitted operators,
loops and thresholds. The high-band inequality is a
separate parent response-tail requirement, not a bound
that may be borrowed from the classical action.

## Why low-frequency agreement is insufficient

At the level of paired numbers, a parent low part equal
to the nonzero classical low part can be cancelled by an
opposite high part, leaving a vanishing full response.
The native algebraic cancellation check demonstrates
this missing logical implication. It is not a constructed
UV model or a claim that all such cancellations are
physically realizable.

Thus matching the low part alone cannot use the compact
classical signal to exclude a matter-causal parent.
Both error gates and the common-parent assumptions must
be supplied. In particular, a finite spatial projection
does not convert the compact pulse into a finite-temporal-
frequency or automatically EFT-admitted experiment.
