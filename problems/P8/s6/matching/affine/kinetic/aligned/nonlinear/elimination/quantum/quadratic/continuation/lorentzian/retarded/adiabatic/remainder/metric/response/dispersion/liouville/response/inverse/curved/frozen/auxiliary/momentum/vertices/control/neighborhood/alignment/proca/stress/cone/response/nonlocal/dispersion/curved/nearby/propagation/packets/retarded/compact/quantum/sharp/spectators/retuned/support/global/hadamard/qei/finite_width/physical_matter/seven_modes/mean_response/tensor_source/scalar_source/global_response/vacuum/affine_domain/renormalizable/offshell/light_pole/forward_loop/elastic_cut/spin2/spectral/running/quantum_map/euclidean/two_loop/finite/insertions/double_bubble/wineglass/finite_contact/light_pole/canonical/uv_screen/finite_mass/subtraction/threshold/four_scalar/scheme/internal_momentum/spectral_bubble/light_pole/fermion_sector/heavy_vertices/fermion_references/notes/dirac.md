# Inverse-resolvent signs, color and dimensional numerator

Use the same Euclidean Dirac operator
D=gamma.partial+m+y_i Phi+i gA gamma.A and the
same GY14 vacuum reference. For an active flavor
Y=y_i^2; the opposite signs have the same Y.

For a centered bosonic fluctuation X of variance h,
expanding the inverse gives

    average (D+V X)^(-1)=S+h S V S V S+O(h^2),
    inverse of this average=D-h V S V+O(h^2).

Thus the scalar proper inverse correction is
-Y integral D_Phi(k) S(p-k). The two factors i
in the gauge vertices change its sign, giving
+a Cf integral D_A(k) gamma_mu S(p-k) gamma_mu
in Feynman gauge. A noncommuting finite-matrix
calculation checks the inverse relation independently.

The open color line gives sum Ta Ta=Cf identity
with Cf=4/3. It does not give the closed scalar
factor six, closed gauge factor eight, or fourteen
flavors. All fourteen fermions have this gauge
self-energy; only the two active flavors have
the scalar term. The total scalar one-point
source cancels between the opposite Yukawas and
the fixed mean-field convention is retained.
No reducible source tadpole is added to the
proper inverse.

The Clifford algebra gives, before the regulator
is removed,

    gamma_mu[-i slash(q)+m]gamma_mu
      =(2-d)[-i slash(q)]+d m.

The code checks all Euclidean Clifford matrix
entries and the d=4 specialization literally.
The arbitrary-d identity follows by commuting
gamma_mu through one gamma_nu and summing
gamma_mu gamma_mu=d. Set d=4-2 epsilon only
after this step. The d-dependent coefficients
remain through multiplication by loop poles.

The local fermion reference is off shell at
p=0, not an exact charged-particle pole.
Feynman-gauge local coefficients are not
claimed independently gauge invariant.
