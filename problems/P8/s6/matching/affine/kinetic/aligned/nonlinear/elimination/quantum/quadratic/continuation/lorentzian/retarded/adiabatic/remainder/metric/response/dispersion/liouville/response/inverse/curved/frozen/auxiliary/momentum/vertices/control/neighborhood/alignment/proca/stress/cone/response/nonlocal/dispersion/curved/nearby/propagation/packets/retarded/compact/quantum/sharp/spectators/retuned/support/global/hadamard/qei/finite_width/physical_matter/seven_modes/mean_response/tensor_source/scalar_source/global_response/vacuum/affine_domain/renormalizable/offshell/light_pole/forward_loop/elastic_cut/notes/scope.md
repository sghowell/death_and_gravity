# Finite-order evidence boundary

Established for the same polynomial vacuum: the actual one-loop elastic
cut below s=6, a strictly nonzero integrated absorptive weight, its exact
angular form and continuous threshold prescription, and a quantitative
positive lower bound for the tree-plus-one-loop forward coefficient
after subtracting that cut.

The loop order is essential. Perturbative unitarity determines the
one-loop discontinuity from the tree amplitudes, with the same physical
mass-one external normalization. It does not bound higher-loop corrections
to the physical cross section or the real coefficient. The selected
window is intentionally below the unstable heavy resonance.

The calculation proves neither the global twice-subtracted dispersion
relation nor its high-energy contour hypothesis. It is not a finite-gravity
argument, and does not transfer the vacuum observables through the
classical derivative field map to the rolling bounce.

No original row is excluded or completed by this finite set of necessary
vacuum checks. Original V/G/B, P8(b) and P8 remain OPEN. Frozen actions,
source/report hashes, old cosmological states and counterterms are unchanged.

The explicit continuum, angular-monotonicity, phase-space and perturbative
cutting arguments are source-pinned written proofs, not proof-assistant
formalized or peer reviewed. Exact algebra, parameter bounds, API inputs
and report mutations are independently replayed with unmodified
scientific SymPy.
