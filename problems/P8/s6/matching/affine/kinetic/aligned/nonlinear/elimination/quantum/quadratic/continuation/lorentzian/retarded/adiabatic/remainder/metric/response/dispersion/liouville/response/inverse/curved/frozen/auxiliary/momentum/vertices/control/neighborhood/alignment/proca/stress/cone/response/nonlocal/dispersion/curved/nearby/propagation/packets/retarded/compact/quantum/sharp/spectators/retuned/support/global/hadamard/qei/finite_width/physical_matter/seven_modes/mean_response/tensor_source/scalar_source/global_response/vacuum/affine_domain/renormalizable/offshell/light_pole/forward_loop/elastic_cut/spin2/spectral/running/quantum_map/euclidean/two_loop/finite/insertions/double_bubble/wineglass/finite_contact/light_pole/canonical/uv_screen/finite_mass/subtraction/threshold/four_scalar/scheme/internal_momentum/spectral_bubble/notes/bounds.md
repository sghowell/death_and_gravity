# Strict positive family coefficient and rational actual bound

Set s=2+v, u_crossed=2-v. The two crossed channel functions have cancelling
linear terms, and their v^2 coefficient is B''(2), not B''(2)/2.
The zero-transfer channel is constant in v. With the already included
two internal insertion positions, the literal family's coefficient is

    b2_family=(L^2/Q) integral_T^infinity w(u)
                 integral_0^1 A^2/Delta(2)^2 dx du.

For nonzero L and Y>0 the integrand is strictly positive on an open set.
The spectral and parameter estimates give

    0 < b2_family <= (L^2/Q) integral_T^infinity 16C/(3u^3) du
                 = 8 C L^2/(3 Q T^2)
                 = N Y L^2/(3 Q^2 mF^4).

The same bound controls the crossed sum's quadratic remainder on the
unit disc, using the uniform second derivative and the segment Taylor
formula. It is not merely a sample at real s=2.

Use mF=10^200, the unchanged leading quartic reference L, the inherited
rational upper endpoint for Y, N=6 and Q>144. The rational upper bound
is below 10^-1418 and below 10^-819 times the positive tree reference
4 lambda. The once-subtracted channel's linear envelope coefficient is
below 10^-1017.

Zero Yukawa or zero quartic coupling yields a zero family coefficient,
not strict positivity; negative finite real L is allowed because L^2
enters. These generic-domain controls do not change the actual positive
boundary. All inequalities are exact rational enclosures, not decimal
cancellation of large local mass references.

The error ledger includes only this literal insertion family. Other
new-model two-loop contributions, finite scheme conversions and all
later-loop/truncation bounds remain separate.
