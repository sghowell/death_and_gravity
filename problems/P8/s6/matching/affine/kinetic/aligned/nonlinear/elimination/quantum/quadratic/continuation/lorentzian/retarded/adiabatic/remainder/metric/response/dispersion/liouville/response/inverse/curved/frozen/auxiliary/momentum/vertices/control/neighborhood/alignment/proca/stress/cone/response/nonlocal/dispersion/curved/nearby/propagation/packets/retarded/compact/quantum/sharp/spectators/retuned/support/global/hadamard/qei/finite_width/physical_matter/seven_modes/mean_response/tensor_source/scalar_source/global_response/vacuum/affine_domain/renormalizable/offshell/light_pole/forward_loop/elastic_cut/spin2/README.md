# P8 S6.115 — actual matter spin-two form factor

The same polynomial vacuum, now with an explicitly specified minimal
Einstein coupling, has a calculable one-loop matter stress form factor.
Both internal light and heavy stress insertions are retained. Their
zero-transfer sum agrees with the already fixed light-residue
counterterm, so the gravitational charge is one without a new retuning.

The spin-two slope is strictly positive and below 10^-405 in light-mass
units. It produces a negative finite correction to the t-channel graviton
pole coefficient after the tree pole is subtracted at fixed negative
transfer. At Planck mass 10^400, the magnitude of this particular
one-loop vertex correction is below 10^-1205.

This is **not** the full gravitational coefficient or Delta_grav:
other exchange channels, graviton loops, higher-curvature matching and
the high-energy Regge/contour contribution are not supplied.
The minimal scalar Einstein model is still not a flat-bounce parent.
Original P8 remains OPEN.
