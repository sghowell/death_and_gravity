# Prospective calibration and infrared scale

Let L0 be the literal scalar quartic in S6.110 and the
old two-loop chain. Assign L(muF)=L0 only as a prospective
boundary condition for this new screen. This assignment
does not compute finite matching counterterms or transfer
the old complete amplitude to the enlarged field content.

Choose mF=muF=10^200 in old light-mass-one units. The
literal old heavy scalar has M=mH^2<mF^2; the named
Planck scale is 10^400. From the positive ray set
aF=L0/rL and yF^2=(19/45)aF. Since 1<rL<2,
0<19/45<1 and pi>3,

    0<|C|<L0^2/(432 mF^2)<10^-810,
    0<K<8[L0^2/(432 mF^2)]^2/9<10^-1620.

The displayed upper bounds are rational and checked using
the actual inherited parameters, with L0<3 times 10^-205.
No floating approximation decides their signs. Their
smallness does not turn either coefficient into zero.

Below all fermion thresholds, the leading running gauge
theory has b_IR=11. In its one-loop approximation,

    a(mu)=aF/[1+22 aF log(mu/muF)/(16 pi^2)].

On 1<=mu<=muF, log(muF)=200 log(10)<600 and
the denominator differs from one by less than
22 L0 600/144 < 10^-200. This is a one-loop running
estimate, not a full threshold or nonperturbative theorem.

The associated formal scale is
log(Lambda_1)=log(muF)-16 pi^2/(22aF),
which is below 600-144/(22L0)<-10^204.
It must not be identified with an actual glueball mass,
nor used as a rigorous assertion about confinement.
A claimed physical gap would need independent evidence.

The old canonical two-loop scalar budget is included only
with an explicit NOT-new-model label. Fermion boxes,
gauge corrections and finite threshold matching have not
been assigned that budget.
