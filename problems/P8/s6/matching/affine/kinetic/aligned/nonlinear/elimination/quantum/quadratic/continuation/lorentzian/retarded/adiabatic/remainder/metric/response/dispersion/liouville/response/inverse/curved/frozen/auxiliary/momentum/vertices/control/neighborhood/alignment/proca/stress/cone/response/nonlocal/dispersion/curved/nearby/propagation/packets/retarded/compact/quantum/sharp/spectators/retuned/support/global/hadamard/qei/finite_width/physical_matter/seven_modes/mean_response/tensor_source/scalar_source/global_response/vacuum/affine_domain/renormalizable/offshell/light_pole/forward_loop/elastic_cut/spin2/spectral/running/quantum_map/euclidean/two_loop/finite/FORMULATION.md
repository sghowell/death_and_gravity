# S6.121: integrated UV-finite two-loop subsector

Original P8 remains OPEN.

For the same canonical polynomial vacuum, obtain an actual
integrated compact forward-coefficient bound for the 88
S6.120 refinements with no superficially divergent subgraphs.
Exclude, rather than silently discard, the 104 refinements
that need ultraviolet subtractions.

Use the complete heavy propagators and exact graph polynomials.
Derive an absolutely integrable majorant throughout |s-2|<=1,
t=0, u=4-s, including the Gaussian loop measure, Taylor factor
and all frozen external-label Wick weights.

The chosen finite subset needs no ultraviolet counterterm
to define its bare integrals. It is not a complete
renormalized two-loop scattering calculation: the excluded
graphs, counterterm insertions and light mass/residue/LSZ
corrections still require separate work.

This finite-subsector result does not bound all higher loops,
high-energy contours, finite-gravity effects or a common
cosmological parent. Original V/G/B is not closed.
