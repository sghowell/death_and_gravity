# Working feasibility note: an all-time variable-lapse continuation

This is a separately specified exploratory action, **not** the frozen
S6.20 constant-lapse family and not a certified P8 ledger result. Its purpose
is to check whether the local background obstruction can be removed before
investing in a proposed global matching theory.

The algebra and written bounds give an all-time physical CD scale factor,
a monotone canonical clock, a free canonical spectator and a regular
positive square-root branch. The hidden metric has bounded curvature in
its own clock. However, the algebraic relative tensor mass tends to zero
as `4/(tau^2*u^30)`, not to a uniform heavy threshold. This prevents treating
the construction as the simple uniformly-heavy extension of S6.20.

Read the [candidate definition](FORMULATION.md) and
[feasibility argument](notes/feasibility.md). The exact checks use symbolic
background equations and a separate Fraction/Bernstein implementation.

operator map, low-energy source-error bound, cutoff or UV verdict exists.
