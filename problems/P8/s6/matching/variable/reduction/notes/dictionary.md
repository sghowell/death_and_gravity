# A fixed-frame formal dictionary and its necessary matching remainder

This is the dictionary component of S6.30. It concerns a formal local
stationary-f derivative expansion of the unchanged S6.20 action, not an
assumption that this expansion approximates its actual rolling solution.
The physical metric is g and chi is its genuinely free canonical scalar.
All scalar-only clock changes below leave g and chi unchanged. There is no
physical cutoff, selected heavy state, Regge result or P8 closure here.

## 1. Exact formal starting point and sign convention

Use signature +---, R_B=-6(Hdot+2H²), Einstein action -M² R_B/2, and
X=(dphi)², Y=(dchi)² without factors of one half. In the actual positive
branch 2<c<=4 the local coefficient profiles have beta1>0 and beta4<0.
At each coefficient value set

```
r=(-beta1/beta4)^(1/3)>0,
f0=r(phi)^2 g,
kappa=M^4 r^3/(4 beta1)>0.
```

Here r is the stationary proportional root of the f potential equation,
not the rolling f/g spatial ratio and not a new flat vacuum. The original
g and scalar equations need not hold on this off-shell configuration.

For f=r²(g+h), with indices on h contracted using g, the literal potential
quadratic at the stationary root is

```
L_pot,2=-(beta1*r/4)[h:h-(tr h)^2].
```

It follows by expanding Tr sqrt(I+h) and sqrt det(I+h), then using
beta4*r³=-beta1. The linear term vanishes. The own-f Einstein variation
is +(M²r²/2)B:h, where B_mu nu=G_mu nu[f0]. Trace reversal therefore gives

```
h=(M² r/beta1)[B-g tr_g(B)/3],
L4=kappa[B:B-tr_g(B)^2/3].                           (1)
```

These are formal derivative-order identities; the next h derivative
correction begins at a higher formal order. They are not bounds on the
inverse of the actual rolling differential operator. The companion
stationary proof varies the full potential and checks this elimination.

The zeroth/two-derivative terms, modulo the stated curvature divergence,
are

```
L0+2=-M²(1+r²)R_B/2
      +[1/2-3M²(r_phi)^2]X+Y/2-2(beta0+3r beta1).    (2)
```

In particular the scalar kinetic correction in this Jordan frame has a
minus sign. Directly, sqrt|f0| R_B[f0] equals
sqrt|g| r²[R_B-6 Box log r-6(d log r)²]. The weighted Box term integrates
to -2r²(d log r)², producing (2) with the Einstein sign above. That sign
does not, by itself, classify a scalar kinetic eigenvalue of the parent.

## 2. Full integration-by-parts dictionary

All derivatives in this section are with respect to the parent's phi.
Put q=(log r)_phi and q1=q_phi. Let H_mu nu=phi_;mu nu, v_mu=phi_,mu,
T=Box phi, and vHv=v^mu H_mu nu v^nu. The conformal Einstein tensor is

```
B_mu nu=G_mu nu[g]-2q H_mu nu+2(q²-q1)v_mu v_nu
         +g_mu nu[2q T+(2q1+q²)X].                 (3)
```

The curvature/Hessian cross part of (1) is

```
-4kappa*q G:H+4kappa(q²-q1)Ric:vv+2kappa*q1 R_B X.
```

The Bianchi identity and a weighted integration by parts replace it by

```
j Ric:vv-2q*kappa_phi R_B X,
j=4q(kappa_phi+kappa*q).                           (4)
```

The curvature-independent square in (1) is

```
kappa[4q²(L1-L2)-8q(q²-q1)vHv
      -4q(q²+2q1)X Box phi-12q²q1 X²].             (5)
```

The independent invariant contractions in checks() reproduce all five
coefficients in (5). The two further weighted identities used are

```
j Ric:vv  == j(L2-L1)+j_phi[X Box phi-vHv],
m vHv     == -(m/2)X Box phi-(m_phi/2)X²,           (6)
```

where == means equality modulo a local divergence. For example,
div(v Box phi-H.v)=L2-L1-Ric:vv proves the first line. These identities
do not invoke a field equation or discard any matter term.

Retain the full operator kappa(Ric²-R_B²/3) separately. In the resulting
quadratic scalar-Hessian normal form the complete coefficients are

```
F2 = -M²(1+r²)/2 -2q*kappa_phi X,
A1 = -4q*kappa_phi = 2F2_X,     A2=-A1,
A3=A4=A5=0,
K = 6[(q²+q_phi)kappa_phi+q*kappa_phiphi] X,
F = -2(beta0+3r beta1)+[1/2-3M²(r_phi)²]X+f4 X²,
f4=2[kappa_phi(2q³+2q*q_phi+q_phiphi)
      +kappa_phiphi(q²+2q_phi)+q*kappa_phiphiphi].  (7)
```

The coefficient f4 is half the contribution to F_XX, not F_XX itself.
Equation (7) is on the quartic Horndeski locus. In particular it is not
the frozen CD scalar-tensor action. A useful nontrivial omission control
is constant kappa: every scalar-dependent term generated by (1) in (7)
then vanishes, even when r varies. This agrees with the four-dimensional
conformal invariance of the curvature-square combination up to the Euler
divergence. In general kappa varies, so kappa times the Euler density is
NOT a disposable boundary. The expression retained here is Ric²-R_B²/3,
not a claim that only Weyl² remains as a nonlinear covariant operator.

## 3. Clock covariance and the exact open-tube center defect

The physical CD clock is theta=τu. The prescribed parent clock is

```
phi(theta)=M integral_0^(theta/τ) sqrt(kbar(v,c)) dv,
J=dphi/dtheta=(M/τ)sqrt(kbar)>0,
X_parent=J² X_theta.                               (8)
```

On the same scalar-tensor normal form a scalar-only clock change gives

```
F2_Xtheta=J² F2_Xparent,
A1_theta=J² A1_parent,
A3_theta=J^4 A3_parent,
GT_theta=GT_parent (at the corresponding X).        (9)
```

The J_phi terms in the Hessian transformation affect F and K, but do not
alter these quadratic-Hessian weights. Thus Xi=A1-2F2_X has weight J²;
Xi itself must NOT be called an unweighted scalar invariant. Where GT is
nonzero the ratio

```
I = X(A1-2F2_X)/GT                                 (10)
```

is invariant under this clock reparametrization. It also does not depend
on an overall positive action/Planck normalization. Its zero detects the
quartic Horndeski locus in the stated normal form. It is not claimed
invariant under arbitrary derivative metric or matter redefinitions.

The actual coefficient profiles are even in u. At u=0 their stationary
root obeys

```
r=2, r_phi=kappa_phi=0,
kbar=64/c-801/100>0,
beta1=(M²/τ²)32/[c(c-2)],
kappa=M²τ² c(c-2)/16.                              (11)
```

Grant the best leading tensor-value fit M_star²=5M² at X_theta=1. This
does not authorize changing the parent's fixed chi background amplitude;

|---|---:|---:|

Consequently I_retained=0 and I_CD=1 throughout this positive open tube.
The two F2 values coincide at X_theta=1, but their normalized X derivative

derivative mismatch. At X endpoints approaching 9/10 and 11/10 the F2

This normal-form clock invariant complements, rather than replaces, the

In particular GT in (9)--(14) is the scalar-tensor normal-form coefficient,
not a kinetic response of the entire fourth-order operator. Derivatives of
its retained kappa can enter that operator's lower differential orders;
they have not been folded into GT or silently omitted from the full action.

## 4. Quantitative necessary remainder, not a sufficient EFT test

Suppose a proposed local reduction writes its matched quadratic-Hessian
coefficients as (7) plus Delta F2, Delta A1 and the other retained or
omitted contributions, in this declared physical-frame normal form.
If higher operators cannot yet be assigned such a controlled decomposition,
this premise has not been established; the calculation does not supply it.

At theta=0, X_theta=1, exact CD matching requires

```
Delta A1-2 Delta F2_X = M_star²,
|Delta A1|+2|Delta F2_X| >= M_star².                (12)
```

In particular matching A1 and F2_X individually gives Delta A1=0 and
Delta F2_X=-M_star²/2. A coefficient tolerance
`|Xi_eff/M_star²-1|<=eta<1` instead implies the necessary floor

```
|Delta A1|+2|Delta F2_X| >= (1-eta)M_star².          (13)
```

This is a C1-in-X coefficient remainder norm, not a norm on action values
or on one chosen solution. There is also an invariant version. If

```
|GT_eff/M_star²-1|<=epsilon_T<1,
|I_eff-1|<=epsilon_I<1,
```

then GT_eff is positive and Xi_eff=I_eff*GT_eff at X_theta=1, yielding

```
|Delta A1|+2|Delta F2_X|
 >=(1-epsilon_T)(1-epsilon_I)M_star².               (14)
```

Ten-percent errors in both quantities still require a normalized
remainder at least 81/100. These are triangle/product inequalities, not
a claim that a source or EFT realizes equality. The positive normalization
is explicit in the interfaces; float, Boolean, nonfinite and symbolic
numerical-domain inputs are rejected.

The polynomial derivative grading in (1)--(7) is NOT automatically an
expansion on the original X_theta approximately one tube. In particular,
L3 has six total spacetime derivatives when multiplied by a coefficient
depending only on the clock, but the actual CD coefficient contains 1/X.
That inverse-X factor changes the homogeneity under scaling clock
derivatives; it is incorrect to assign the target to a later perturbative
order by counting L3 alone. Higher formal orders, their clock derivatives,
or a resummation can contribute to finite-tube coefficient jets, and the
original beta-profile derivatives can enhance such terms. Repairing the
displayed finite-tube defect still requires the quantified remainder size
(12)--(14). No smallness follows from formal order or from the large
instantaneous center mass. The result is not an exclusion of a resummed,
differently prepared or otherwise more general matching model. The
separate fourth-tensor-symbol error also belongs in its declared budget.

## 5. A metric redefinition moves, rather than removes, the matter issue

Write Q=M²(1+r²)>0. To cancel the displayed pure curvature-square term at
this formal order, consider the explicit INVERSE-metric redefinition

```
g_old^{mu nu}=g_new^{mu nu}
  +(2kappa/Q)(R^{mu nu}-g^{mu nu}R_B/6).            (15)
```

The -Q R_B/2 variation gives -kappa(Ric²-R_B²/3), together with additional
terms from derivatives of Q. In the +--- convention used here

```
T_chi,mu nu=chi_mu chi_nu-g_mu nu Y/2,
delta S_chi=(1/2) integral sqrt|g| T_chi,mu nu delta g^{mu nu}.
```

It therefore also gives the unavoidable displayed matter contribution

```
Delta L_chi=(kappa/Q)[Ric_mu nu chi^mu chi^nu-(R_B/3)Y]. (16)
```

With a covariant-metric perturbation the intermediate variation has the
opposite sign; mixing these conventions would give a wrong contact. The
implementation contracts all ten independent Ricci entries and all four
chi-gradient components. A separate test differentiates the literal
volume and inverse metric in a one-component fixture.

If curvature is additionally traded using the leading metric equations,
the pure-chi part becomes +(2kappa/(3Q²))Y²; mixed clock, potential and
derivative-Q contacts remain. Indeed T_chi:T_chi=Y² and tr T_chi=-Y, so
the trace-subtracted contraction is 2Y²/3. This is an operator identity
modulo specified leading equations, not a newly assumed stationary vacuum
or a UV positivity amplitude. The generated operators are not in the
frozen free-M1 action. A legitimate matching may retain and bound them;
it cannot remove them by silently calling g_new the old physical metric.

For an independent constant-r normalization check, let G=M², F=M²r²,
nu=2beta1*r and Q=G+F. The full physical-g quadratic source kernel is

```
K2(D)=G D+nu-nu²/(F D+nu)
     =Q D-F² D²/(nu+F D),
K2^-1=1/(Q D)+F/[G Q(D+mu²)],
mu²=nu Q/(G F).                                   (17)
```

The coefficient of Ric²-R_B²/3 is F²/(2nu)=kappa. The leading massive
source contact has coefficient kappa/Q² multiplying
T:T-(tr T)²/3, reproducing (16)'s pure-chi coefficient after the leading
metric equation. The physical observable and its massive exchange have
not been replaced by the massless normal coordinate. This regression
uses a common inverse prescription away from poles. It is not a claim
that the actual local VARIABLE profiles possess a proportional vacuum;
S6.28 proves the contrary on their local coefficient interval.
