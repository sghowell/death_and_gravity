# Reproducibility and publication gates

The private research separates three independent checks:
literal canonical Einstein/matter vertices, rational angular and
Legendre-Q integration, and complete retained-source formal-loop
bookkeeping. Assemble the scientific packet only after these pass.

Run a fresh private source/AST/export/count/gate/hash/Float-free check
and all science tests with original SymPy. Format before freezing.
Copy every accepted source exactly, verify every byte and hash, and
repeat in a fresh repository process. These source preflights are not
full ancestral report replays.

A separate original-SymPy native process must rebuild every predecessor,
protect existing scientific inputs and return its own raw ASCII report.
Capture the complete stream without reserialization, validate all fields
and source hashes, then freeze both private and repository raw bytes.
Never send research probes or DONE to that native helper.

Publication also requires the actual original-SymPy ordinary tests,
the independent CLI --check and a complete captured P8 FULL regression
that includes this packet. Only that FULL lane may use the separately
audited exact-GCD adapter. Do not relabel an earlier snapshot as new
coverage or report a collection count as a successful run.

External assessments record actual failures, corrections and successful
gate evidence; these notes do not predict future runtimes or verdicts.
Source/report bytes stay immutable after freezing. Commit only exact
validated paths, preserve unrelated P4/P9 and verify the public remote.
